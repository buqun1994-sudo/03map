<TextSize=28><TextColor=255,255,255,230><Paragraph=0,0,0,16>1. What is the use of offline maps?</Paragraph></TextColor></TextSize>
<TextSize=24><TextColor=255,255,255,153><Paragraph=0,0,0,40>After downloading the offline map, the software will automatically use the offline map to search and navigate when there is no internet or a weak network. Offline maps of some cities also support the functions of large intersections and three-dimensional intersections.</Paragraph></TextColor></TextSize>
<TextSize=28><TextColor=255,255,255,230><Paragraph=0,0,0,16>2. How to download and update the map?</Paragraph></TextColor></TextSize>
<TextSize=24><TextColor=255,255,255,153>On the map, click the more button in the upper left corner and select [Offline Data]. We provide you with two ways to download and update data.</TextColor></TextSize>
<TextSize=24><TextColor=255,255,255,153>Method 1: Online update. Click [Offline Map] to download map data directly</TextColor></TextSize>
<TextSize=24><TextColor=255,255,255,153><Paragraph=0,0,0,40>Method 2: U disk update. Go to the official website (www.amapauto.com) to download the map data package, unzip it and store it in the root directory of the U-disk, enter [Offline Data]-[U Disk Update], the data in your U-disk will be automatically identified, you can select the data to be updated.</Paragraph></TextColor></TextSize>
<TextSize=28><TextColor=255,255,255,230><Paragraph=0,0,0,16>3. How to change the storage location?</Paragraph></TextColor></TextSize>
<TextSize=24><TextColor=255,255,255,153><Paragraph=0,0,0,40>Enter [offline data]-[change storage location], you can select the storage location where you want to store offline data, and we will move the data you have downloaded to that storage location.</Paragraph></TextColor></TextSize>
<TextSize=28><TextColor=255,255,255,230><Paragraph=0,0,0,16>4. I inserted an external card/U disk, why is it not recognized?</Paragraph></TextColor></TextSize>
<TextSize=24><TextColor=255,255,255,153><Paragraph=0,0,0,40>Please check whether the external card/U disk is inserted firmly. If it is inserted firmly and other file management software can recognize it, please try to create a file under the external card. If the creation fails, it may be that the external card is damaged or the system has restricted the use of the external card. It is recommended to replace the external card or contact the system owner.</Paragraph></TextColor></TextSize>
