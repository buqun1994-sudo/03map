## 3. 资源定位入口

| 资源目录/文件 | 当前用途 |
|---|---|
| res/layout/main_map_view.xml | 地图 Surface 与 UI Surface 的基础布局 |

| res/values/ids.xml | map_surface、ui_surface 等资源 ID |

## 4. 维护方式

本清单用于规模和目录导航，不是完整类索引。新增高价值入口优先写入主链索引；只有目录规模、DEX 分布或版本切换时才更新本文件。
