## 施工目标 (Objective)

1. 在当前高德 `9.5.0.600013` 左侧内容区按 SVG 复刻**视觉语言和整体层级**：真正居中的默认时间、只有数值的右侧剩余里程、无普遍外框的柔和卡片、一体式横向媒体卡、简洁 Dock 与来源弹层。保留两页、两控制卡、真实媒体／车控状态和可滑动能力，但**不展示页码点、不保留快捷页设置横条**；不从原型重复卡片虚构功能。
2. 两类交互控件都要可复用：方形按钮统一承载车锁、主驾通风／加热／按摩的点按行为，按摩不是纵向滑条；纵向滑条只用于已经接入系统端口的亮度和媒体音量。座椅按钮的循环选档共享同一 Store／Port，不形成第二套写入；没有正式能力证据的控件不画成可操作假功能。
3. 五种来源的用户可见名称固定为“蓝牙音乐、爱趣听、网易云音乐、USB音乐、本机音乐”；“U盘音乐”仅作为输入别名映射到“USB音乐”。五项各有原厂提取图标；原型中的图标、专辑图、示例温度、续航和功率都不作为业务数据或素材。

## 根因与物理定位 (Root Cause & Anchors)

1. 正式 `content-src/com/autonavi/amapauto/content/ContentRenderer.java` 的 `buildTopBar()` 把时间放进左侧加权容器，`renderTopBar(ContentState)` 仅在**左侧剩余宽度**内居中，并给剩余里程加可见“续航”前缀；默认时间不是内容区几何中心。
2. 同文件 `roundColor(int,int)` 无条件调用 `setStroke(dp(1), theme.divider)`；`applyThemeToView()`、`renderTile()`、`renderDockState()`、`buildMediaCard()`、`createControlButton()` 等复用它，产生快捷卡、滑条、媒体内按钮和 Dock 各槽层层套框。`ContentTheme` 的浅色填充令牌虽已接近 SVG，却未实现 SVG 的浅灰／白底＋柔和阴影的层级关系。
3. `buildShortcutsPage()` 还添加横向“设置暂不可用”提示卡；`buildPages()`／`renderPage()` 额外建立并绘制页码圆点；`buildControls()`／`buildMediaCard()` 仍把曲目信息放上排、三枚有框操作放下排。以上是旧 UI 骨架残留，不是 SVG 的一体式媒体卡与无圆点页面。**原型中的重复座椅图形只是形态占位，不是缺失功能，也不是造成描边的原因。**
4. 五来源名称／原厂 Vector、滑条直选和车控／媒体端口已进入正式源码；其图标 owner 是 `ContentIconView.stableResourceName()`，资源来源与哈希由 `assets/content-oem/asset-manifest.json` 管理。本轮纠偏仅调整呈现层；保留 `ContentRegistry` 来源映射、`ContentStore` 待确认、`ContentVehicleAdapter` 实车安全链、`ContentRuntime` 生命周期和 `SplitPanelController` 地图几何。

## 执行步骤 (Execution Framework)

### 1. 参照画面与视觉令牌

1. 原型身份：`Group 77.svg` SHA-256 `0b9e524d83e098602dcae273f31bf05841d14ee56b3381cc6fe80a04a01e9287`，`Group 78.svg` SHA-256 `d1f281c47bb27235db8a5ffb0004d8f6ea626f0f6593814299ffe5f8d8038cd5`，均为 **640×1080、viewBox 0 0 640 1080**。`77` 为来源菜单关闭态，`78` 增加位于原型坐标 `(520,420)`、`100×400`、圆角 `12` 的展开态；坐标是参考画布像素，**不是车机 dp**。
2. 原型实测：背景 `#F4F4F4`；普通方块 `#E9E9E9`；选中方块／媒体卡／菜单 `#FFFFFF`；主色 `#27303B`；辅字 `#666666`；参考蓝 `#2F8DFF`。方块列左边缘 `20/175/330/485`、宽 `135`、列间 `20`、圆角 `12`；首行 y=`59`、第二行 y=`214`，高方块 `135×290`；媒体卡 `(20,832)`、`600×120`、圆角 `12`；Dock 主要内容位于 y=`968–1068`。SVG 多个卡片的投影为向下 `2px`、高斯模糊标准差 `2px`、黑色约 `15%` 不透明度的**轻阴影**，普通卡／选中卡／媒体与底栏**没有逐卡描边**；内部只有媒体卡右侧的一条 `#DEDEDE` 细分隔线，外侧内容与地图的边界另按分屏边界管理。SVG 右侧细竖条是**纵向滚动位置提示**，不是底部双圆点页码；亮绿电池和示例歌曲仅作示意。
3. **目标机规格**以真实内容 viewport 宽高与 `DisplayMetrics.density/scaledDensity` 换算；`1920×1080、density=2、内容宽 640px` 只作本机对照，**不可把 640px 等同 640dp**。640×1080 对照应先以 SVG 的像素锚点排布与柔和投影成像，再按实际密度保障文字和触摸热区；不要因为采用 `10dp` 边距或 `6dp` 圆角便跳过实际 `20px` 边距、`12px` 圆角的截图校验。四列宽度随可视宽度重算，实际可交互方块至少 `64dp` 宽、触摸至少 `48×48dp`；四列不足时降为三／两列，绝不缩小字号或挤到地图侧。高条随列宽适配；页面允许纵向滚动，媒体卡与 Dock 不进入该滚动层。**卡片数量按真实功能决定**，占位按钮数量及图标不进入最终 UI，不用假控件撑密度。
4. SVG 的文字已经转为 path，**无法直接读出字族、字号或字重**。当前正式实现统一使用 APK 内高德 `Roboto-Regular.ttf`／`Roboto-Bold.ttf`：顶栏温度 `16sp Bold`、时间 `17sp Bold`、里程 `16sp Bold`，状态 `12sp Regular`；功能名称 `14sp Regular`，卡片曲名 `16sp Regular`、歌手 `13sp Regular`，菜单名 `12sp Regular`。本轮只提高顶栏字重，不以改字号代替字重调整；用 Android `Paint` 和截图逐类校准重量、基线及可读性，任何关键字／数值不横向裁切。不要把 SVG 路径或文字栅格图嵌进界面。
5. `ContentTheme.light()` 把上述色值映射为语义令牌，其他中性／状态色从同一主题推导；`dark()` 使用中性黑灰层级：背景 `#0F0F0F`、普通表面 `#1A1A1A`、提升层 `#232323`、选中层 `#2D2D2D`、按下层 `#414141`，并校验对比度，不把浅色 SVG 简单反相。主题切换仍只跟随高德回调，背景可继续在媒体有真实专辑图且正在播放时显示唯一全局氛围层。
6. **外观不等于可点击边框：** 将填充圆角、选中底色、柔和投影、局部分隔线分成独立的呈现角色；不能再让公共 `roundColor()` 给所有角色强制加 `1dp` 描边。按钮交互靠按压／状态动画和底色体现，不靠常驻边线；投影范围、抗锯齿与裁剪要在实际宿主绘制帧核对。无真实数据的 `--`、无媒体态只改变内容，不得自动生成旧式有框容器或“暂不可用”横幅。

### 2. 布局、状态与交互

1. `buildTopBar()`／`renderTopBar()` 保持**单行**，但默认时间必须按**内容区实际宽度的 50%**定位：文字可视边界中心与内容区中线在 640px 参照帧偏差 `≤4px`，不可按“左侧温度与右侧里程剩余宽度”取中点。确认未插枪时显示“左车内温度－几何正中时间／星期－右**原始数值**＋原厂电池图标”；不可输出“续航”前缀、可见“未插枪”或百分比。数值无效时仅为 `--`，不显示“续航 --”；无数据不等于未插枪，电量百分比仅保留在无障碍说明。长文案不得碰撞时间；极窄内容区先明确优先级与适配，再验单行，不以悄悄偏移中心代替。
2. 非默认充电状态切到“**最左**紧凑时间－右**状态文字紧挨原始数值之前**＋电池图标”，车内温度让位，时间不再要求居中。已插枪但未确认充电只写“已插枪·状态待确认”；预约组合写“预约等待中”；充电组合优先写“功率 *kW* · 剩余 *分钟*”，**只在独立真实功率／剩余时间值有效时逐项显示**，否则写“充电中”。其它组合写“充电状态待确认”，状态词不能靠默认值推断；原型示意图中的“已插枪·等待充电”须等当前车型取得独立等待状态证据才可替换。长状态只压缩其自身文案，时间、原始数值及电池图标保留；单行、不允许互压或换行。示例图中的 `kWh` 不能用作功率；`366km` 只表达数值＋单位的视觉形式，当前车型剩余里程原始值的 `km` 单位尚未与仪表核实，故先显示“366”一类**无前缀原值**，核实后才能补单位。
3. 时间按已记录的星期／秒数偏好显示：默认态 `HH:mm·星期X`（秒数开时 `HH:mm:ss·星期X`），非默认态只用紧凑时间 `HH:mm`（秒数开时 `HH:mm:ss`）；不改变既有偏好存储格式，也不额外显示日期。状态切换做旧／新位置和透明度过渡，普通时钟逐秒刷新只改字符，**不重播布局动画**。
4. `buildShortcutsPage()` 保留四枚已接通的方形车控按钮、设置共享快捷按钮与两个系统纵向滑条；具体高条在网格中的位置须跟真实控件共同重新排版，不能孤立右对齐后用设置横条补空白。原型重复座椅卡只是展示普通／选中／滑条形态，绝不当成要新增的车控按钮。`buildPages()` 保留两页滑动，但移除可见页码圆点及其专用占位高度；可访问页名称不删。设置入口仅保留原型 Dock 里的图标，设置未就绪的提示留在点击反馈，不在快捷页铺整行。滑条底端关闭 `0`，上方 `1/2/3` 档；向上增加、向下减少。拖动只更新预览；`ACTION_UP` 用 `fraction = clamp((滑条底边−触点Y)/有效高度, 0, 1)`、`target = round(3×fraction)` 得到 `0–3`，分界为 `1/6、1/2、5/6`，通过**既有** `ContentStore.setSeatLevel(String,int)` 提交一次。`ACTION_CANCEL`、无状态、待确认／系统拒绝均不得写入；相同档位不重发，失败／断连／6 秒超时回弹实际档位。强度已开启但读数未知时显示“档位未知”，仍可沿安全关闭路径关闭，不猜选中档；方块循环选档和 Dock 行为不变。
5. `ContentStore.setSeatLevel()` 已复用 `cycleSeatLevel()` 的请求 ID、Pending、超时和失败／回读判定，不自行操作 Binder；`ContentRenderer` 只持有拖拽中的**临时预览位置**，不能在 UI 层持久化车控真值。`ContentVehicleAdapter` 的 Binder 编号、安全守卫、单目标请求及真实回读保持原样。
6. `ContentRegistry` 维护五个稳定来源 ID／显示名与旧短名兼容关系；`ContentMediaAdapter` 保留现有来源码 `蓝牙=2`、`爱趣听=4`、`网易云=9`、`USB=1`、`本机=3`，只更新显示名与归一化，不更换原厂服务调用协议。菜单触发区显示当前来源图标与名称，弹层显示另外四种来源的**各自图标＋完整名称**；关闭态和打开态对应 `77/78`。弹层以锚点右侧对齐，实际宽度按文字测量并至少 `120dp`，限制在内容区可视边界，避免把 SVG 的 `100px` 固定照搬导致文字不可读；空间不足时只滚动菜单，不盖到地图操作区。选中后等真实媒体回流确定来源，不把请求发送成功当成已切换。
7. `buildControls()`／`buildMediaCard()` 保留可滑动的媒体／空调模块，但媒体卡的默认态必须复刻 SVG 的**单一白色横向底座** `(20,832,600,120)`：左侧封面示意宽 `120px`，紧随两行曲目信息，中部播放与下一首，右侧来源区以前述 `#DEDEDE` 细竖线分隔；**不能上排信息、下排三个带框按钮**，不能给内部控件重复底座／阴影／描边。无媒体时显示真实空态文本，卡片结构仍保持。`buildDock()`／`createDockButton()` 保留六个功能位、固定车锁与长按替换，视觉复刻一个整体白色底座、左侧独立锁区、当前入口一块浅灰柔和选中底、其他入口裸图标；不对所有入口叠框或复用媒体按钮样式。Dock 的设置图标不表示快捷页另有设置横条。

### 3. 动画、原厂资源和物理边界

1. **所有用户可见交互均有可观察动画：** 按下 `200ms` 缩至 `0.96`、松开／取消 `240ms` 恢复；方块选中／档位变更 `260ms` 过渡；滑条拖动随手实时跟随（帧内更新，不用补间阻碍手指），失败回弹沿端口反馈；来源菜单进场 `240ms`、退场 `200ms` 位移＋淡入淡出；顶栏状态切换 `320ms`；页面／控制卡与主题切换 `700ms`。连续点击车控时从 pending 目标档位继续计算；重新绘制同一状态、时钟更新不重播。`pause()`、`destroy()`、弹层消失均取消各自动画／回调，不持有失效 View。
2. 所有**图标图形**须来自已提取的原厂系统／音乐应用资源；本机有 `com.android.systemui.plugin` 解包的静态 Vector 候选：`ico_bluetooth.xml`、`ico_media_aiquting.xml`、`ico_media_neteasy.xml`、`ico_devices_usb.xml`、`ico_media_local.xml`，均位于被忽略的 `.tmp/icon-inventory-20260928/plugin-decoded/res/drawable-anydpi/`。施工先校验原始 APK 条目、XML 依赖／明暗色和哈希，逐项登记到正式 `assets/content-oem/asset-manifest.json`，再纳入 `res/drawable/content_oem_*.xml`；`ContentIconView` 提供五个稳定 key。源 SVG 图标不能兜底；若某候选无法安全渲染，先查同机其它原厂资源而不是画代用品，不得称“五图标完成”。媒体封面继续取真实 MediaSnapshot，不使用 SVG 内嵌示例 JPEG。
3. **文件头与编码锚点：** 优先在正式 `ContentRenderer.java`、`ContentTheme.java`、`ContentIconView.java`、`ContentRegistry.java`、`ContentStore.java`、`ContentMediaAdapter.java` 原位扩展，UTF-8，不新建 Java 类。若后续有充分理由必须新建 Java 类型，目标仍在同一 `content-src/com/autonavi/amapauto/content/` 包；**逐字复制 `ContentRenderer.java` 文件头及 package**，立即检查类型归属、构建脚本包含关系和最小 Java 编译，未通过不继续。新增的原厂 Vector 从上段已有 `ico_*.xml` 原文件逐字复制头、命名空间和 path，不手写图形；参考打包资源头 `res/drawable/content_oem_ico_media_music.xml`，每加一个立刻做 XML／APKTool 最小解析并核对 manifest。
4. **绝对不能碰：** `SplitPanelController.smali`／地图两条 Surface／125% 密度、包名和签名身份、车控 Binder 常量与权限路径、历史悬浮分支；不新增第三方联网依赖或用系统全局亮度／音量 API 越权替代未验证能力。既有 `shortcuts → lyrics` 两页（默认歌词）、`media → climate` 两卡、固定车锁＋五槽 Dock 和真实媒体氛围背景仍为正式**业务结构**；旧 `ContentRenderer` 的统一描边、设置横条、页码点、双层媒体按钮不是业务不变量，必须改。SVG 仅演示快捷页，不凭一张图更换主页；媒体菜单内重复的“USB音乐／U盘音乐”亦不得覆盖已确定的五来源名单。

2. **必须通过／定向自动化：** 在现有本机内容宿主／状态测试中覆盖 `640/960/1280px` 内容宽及真实密度对照：默认顶栏时间以内容区中线为基准、640px 参考帧偏差 `≤4px`，且显示数值无“续航”前缀、里程无未经确认的 `km`；非默认态时间最左、状态在数值前；任何态单行不重叠。没有可见页码点／快捷页设置横条；座椅通风／加热／按摩均为真实多状态方块按钮，亮度／音量才是纵向滑条；媒体播放、下一首、来源、快捷卡和 Dock 共用按压态且来源常态无背景；媒体卡为一层横向整体，按钮／卡片／Dock 普遍**没有可见描边**，只保留授权的分隔线。原有按摩 `0/1/2/3`、来源五图标与别名、统一 `88px` 来源热区、触控动画、翻页、背景、Dock 触摸／长按回归保持通过。功能断言不替代图像验收。
3. **必须通过／同屏视觉复核：** 对 `Group 77.svg` 与菜单展开 `Group 78.svg` 均生成 640×1080 **完整**画面，并从同一候选 Renderer 在对应密度、相同画布尺寸截取关闭／展开帧；分别并排和半透明叠图逐项记录“时间锚点、右侧里程、色阶、柔和投影、零普遍描边、字重、快捷卡／滑条节奏、横向媒体、Dock、弹层”。原型占位卡、占位图标、示例歌曲／数字和重复 USB 条目不作像素对齐要求，保留真实功能和五来源规则；不允许因排除了示意内容便跳过**真实控件的质感和固定区域结构**。关键固定元素（顶栏中线、媒体卡四边、Dock 外边）在参考 640×1080 画布偏差 `≤4px`；字体／触摸依实际 density 逐项核对，有差异逐条记因。任何与 SVG 明显相反的统一外框、双排媒体、页码点或设置横条均判视觉不通过，不能因 12/12 功能测试通过而放行。
4. **必须通过／构建和运行：** 从正式 `source/` 执行 `bash scripts/build-content-apk.sh`，只交付签名包；回读包名／版本／单 signer／签名／资源表／两条 DEX／原生库压缩。本机宿主启动正式 Renderer，触发菜单、按钮、滑条拖动／取消、顶栏状态转换并采样动画与上述视觉帧。若目标车机可用且用户未禁止安装，按 [验证矩阵](../testing/验证矩阵.md) 同包保留数据安装并启动，截取默认、插枪／预约／充电**自然出现的**状态及来源菜单开合；滑条写入／失败回弹只有获当次明确授权并满足安全门禁才能在车机触发。记录进程、窗口／Surface 和最小错误日志，不做未经授权的车控写入。
5. **运行级客观阻断与剩余人工：** 车辆未在线、没有真实插枪／充电／预约现场状态、没有授权车控写入时，只能验证本机状态渲染与车机可触发的只读交互；不得造假车辆状态。视觉同屏对照可在本机完成，**车机离线不是跳过本机视觉门槛的理由**；剩余人工才是同一签名包的驾驶视距字重／阴影／触摸手感，以及另获授权、安全可逆的真实滑条写入。任一“必须通过”项失败，不得宣称 SVG 复刻完成。

## 次生风险提示 (Secondary Risks)

本轮正式源码在 `ContentRenderer.java` 原位完成顶栏／网格／媒体／Dock 重排，未新增 Java 类型，未触碰 `SplitPanelController`、密度链或车控端口。呈现角色拆分为普通填充、选中底色、卡片轻阴影和单独分隔线；公共 `roundColor()` 不再加描边。Dock 选中底色从整槽缩到图标区域，不缩小热区；弹层为五来源中**除当前一项外的四项**，其宽度按 `≥120dp` 可读性约束，不照搬 SVG 的 `100px`。媒体 `layoutMediaCard()` 仅在内容宽 `<350dp` 时收窄文字内边距，曲名 `14sp`、来源 `11sp`；`640px`／应用 `265dpi` 的基准仍保持曲名 `16sp`、来源 `12sp`，空态不被截断。实际 `640×1080` 锚点与原型差异、明暗和状态样本见 [本机验收记录](../testing/SVG内容区视觉返工验证记录.md)。本轮用户禁止车机连接／安装，运行级余项归同包现场确认；旧候选的视觉失败仍独立保留。

暂无明确次生风险。实施联动重点是车机实际宽度下顶栏长状态、弹层与地图边界、座椅按钮与滑条共用单目标待确认，以及动画停播；以上已进入必须通过的验收项，不把未发生的推测写成既成回归。
