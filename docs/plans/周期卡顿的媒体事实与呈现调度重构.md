# 周期卡顿的媒体事实与呈现调度重构

本方案记录2026-10-04用户确认后的正式施工职责。字符语义保持正常基线→约1000ms ease-out向上2.5dp→保持终点；已经验收的歌词／封面获取、录音证明、来源权威和车辆命令回报保持原合同。

## 1. 已安装包的诊断依据

现场目标为S56_HQX／SDK28。实际安装整合包SHA-256=`d1d19c0b2e038580b94dba175eef4eefcf7f1bf44711f3e6f182d4210d9b05fa`，对应[构建身份](<../../apk-work/9.5.0.600013/source-build.gsxx97/build-report.json>)；不是上轮隔离歌词候选。全CPU完整trace交集为11.822094秒：主线程CPU running约5441ms，380次doFrame inclusive约2117ms，View.draw录制inclusive约187ms。inclusive与CPU running不直接相减，也不把低录制成本扩张为GPU低成本。

[事务统计](<../../.tmp/lyrics-periodic-diagnosis-20261004/binder-rate.json>)精确包含4542主线程outgoing requests（384.20Hz），4161次同步。149.125ms main-frame gap内120次同步请求，形状为15组3播放状态＋2元数据＋1音频信息＋1Audio mode＋1服务能力；与已记录并发GC span无重叠。方法名与[API28参考映射](<../../.tmp/lyrics-periodic-diagnosis-20261004/api28-binder-reference.txt>)强一致，未采厂商实际descriptor，不冒称动态接口识别。无doFrame不是单独的missed-demand证明；整窗观察含地图、背景和当时其它窗口。同期约63秒gfx聚合为1943帧／1028 janky，不当作30秒或歌词独立结果。

确定的架构缺陷：真实回调数据被舍弃后重复pull；未变化来源结果仍重新仲裁、发布；媒体适配器的外层锁穿透listener、Store、Binding和全态投影。自然GC、formatters、metadata解包、Shader实例重建和GPU上传有各自证据边界，不推为一个未经分解的唯一成本。

## 2. 媒体事实和发布协议

[媒体适配器](<../../source/amap-9.5.0.600013/content-src/com/autonavi/amapauto/content/ContentMediaAdapter.java>)继续拥有公开Session／Browser与原车来源读回，不建立另一套arbiter。

1. Controller callback中的metadata／playback／audioInfo（包括null）就是本次事件事实。缓存逐字段版本，按实际事件顺序准入；选择、分类和快照只读缓存。
2. 首次或重连缺失字段可由worker补读；补读请求固定epoch、token和字段序号，迟到结果只能补仍缺失字段，不能覆盖后来回调。真实暂停、seek、换歌、AVRCP和publisher排序不作latest-only合流。
3. 来源读取最多一项在飞，重复通知只设dirty并追加必要补读；请求固定epoch／service／version／sequence。未变化读回只更新必要的观察与命令反馈，不重新仲裁或发整份媒体状态。
4. 能力由启动、恢复、连接／包变化及实际失败失效；`isSourceAvailable()`读取已准入缓存，不在UI投影做PackageManager查询。音频mode等外部服务读同样由worker拥有。
5. 锁内只更新事实、复制不可变快照与必要副作用描述；退出所有外层锁后执行外部副作用和FIFO通知。listener重入追加下一项，不能带通知锁调用用户代码。销毁、metadata grace、AVRCP、封面完成／超时、来源读回均遵守同一协议。

## 3. 唯一锚点和业务语义调度

[ContentLyricsTimeline](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/ContentLyricsTimeline.kt>)及现有Tracker仍是唯一可信时间线。[LyricsPlaybackAnchor](<../../source/amap-9.5.0.600013/content-src/com/autonavi/amapauto/content/ContentPorts.java>)是不可变basePosition／capturedElapsed／speed／duration／ready／revision；只有实际媒体证据改变轨迹时替换引用。同轨迹重复回报保留原引用，current／sample不回写锚点。不完整初始化零和真实零seek继续分开，AVRCP新鲜度、publisher顺序和暂停恢复不放宽。

[CanonicalSemanticIndex](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/CanonicalSemanticIndex.kt>)编译不可变正文／时长的row timings及真正Cursor变化位置，调用[原Cursor规则](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/ContentLyricsCursor.kt>)，不另造UI游标。保留800ms lead、1200ms tail、500ms主轨／100ms背景overlap、同起点多声部、之前三行和整数边界语义。

[Store](<../../source/amap-9.5.0.600013/content-src/com/autonavi/amapauto/content/ContentStore.java>)从稳定锚点算下个业务边界的单次elapsed deadline。timer只采已有锚点，只在活动／滚动／gap／endpoint等语义变化发布；不再16–100ms更新capturedAt或发布插值全状态。真实anchor／正文／生命周期变化取消重排；零consumer、未知位置、暂停和纯文本不固定ticker。`lyricsPositionMs`保留为低频语义事件sample，UI使用anchor pair，不能把该sample配旧capture。duration到达发布一次端点事实，即使此前真实词尾已清空active。

## 4. 投影和订阅职责

[Mapper](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/ContentUiMapper.kt>)在映射前比较消费域事实，分别保留shell与lyrics对象，不在全态map之后才distinct。正文／waitRows仍按不可变引用缓存。可信duration优先锚点，partial metadata不清已有可信duration。

[Binding](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/ContentBinding.kt>)发布shell、lyrics、clock、artwork独立状态。[实际Compose入口](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/BoundContentPanel.kt>)把clock及lyrics收集放在[顶栏／歌词叶节点](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/ContentPanel.kt>)，不让anchor或时钟换掉整个ContentPanel输入。

[ClockPresenter](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/ContentClockPresenter.kt>)线程封闭复用格式器及Date；显示时分按分钟，秒按秒，weekday按当地日期。时区、时间、locale广播显式失效。时钟不调用Store.updateClock，不读取媒体服务。

系统亮度／音量读写在串行worker，观察及有界fallback更新自己的域。请求具有生命周期和顺序标记，命令发送不判确认；延迟结果不清新失败，停止后不重放旧命令。实际宿主观察时间广播、亮度ContentObserver和音量通知，不让系统服务查询贯穿媒体回调锁。

## 5. 呈现及资源边界

保留已经正确的后台整曲shaping、候选／准入文档与source成对发布、Unicode／RGBA安全运动及批次绘制。[WallpaperLyrics](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/WallpaperLyrics.kt>)从准入anchor只读采样；真实anchor代数／正文／cursor／visibility才打断睡眠，资源发布不重设follow目标。稳定base可以早于endpoint，显式`atEnd`来自Store语义事件，不能因base尚小而继续末行强调。

本轮首要治理事实及调度链。12MiB仍只是ink缓存条目预算，背景10Hz位图轮换、native Shader级联和GPU驻留是独立资源owner；未以缓存池任意复用在飞位图，也未未经同车证据启动新的GL／TextureView后端。若新包仍有资源型顿挫，再按同包trace证明其actual allocation／upload／draw／GPU阶段后处理，不能借上游修复宣称所有成本消失。

## 6. 可执行验收

- 所有媒体producer的listener均`Thread.holdsLock(adapter)==false`，重入和另一线程读取不死锁；不仅单测publish方法。
- 稳态 callback不重复调用媒体getter；来源100次重复通知保持一个在飞、无变化不重仲裁／整发布，过期生命周期和字段pull不能覆盖新事实。
- 相同轨迹10秒采样或重复回报，anchor引用／revision不变，Store发布不按100ms累计。语义边界前／当／后及随机seek与冻结旧resolve逐项一致，暂停、速度、seek和恢复立即重排。
- 仅anchor／cursor事件，shell投影及对象不变；仅clock事件，歌词／壳不重组。真实native Compose tests检验叶节点订阅，不把结构正则当行为证据。
- 系统读阻塞时媒体暂停／恢复和时钟仍即时准入；所有系统服务读写都在worker；停止拒绝排队命令及旧回报。
- 同身份正式签名包安装后核设备APK SHA。同歌同窗相近区间测主线程同步查询谱、锁竞争、帧外CPU、真实帧需求、RenderThread、GC和gfx聚合；控制trace完整buffer边界。不把上轮792项功能回归借作新包性能。
