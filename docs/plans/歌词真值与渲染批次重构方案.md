# 歌词真值与渲染批次重构方案

本轮按用户反馈先定位原因、确定底层职责，再修改正式源码。歌词和封面获取已由用户验收通过；当前工作针对歌词微动态的跳变和绘制负载。

## 根因与证据

- `3072dc0` 的固定上浮公式在源词视觉单元 onset 前返回 -1（绘制 y=0），onset 当刻返回0（绘制 y=+2.5dp），再以1000ms ease-out回到0。开始端点不连续，确定造成先下闪；这不是可信媒体时间线的错位。
- 原生绘制仍按每个有墨迹的视觉单元执行save、可能translate、选Shader、drawRect、restore。该循环及共享edge Shader属于`920488e`既有成本；固定rise提交删除了scale/glow与halo pass，不能仅凭用户体感声称它增加了draw次数。
- 共享edge在每slice调用setLocalMatrix，API28会使native Shader失效；饱和的源词仍走逐cell路径。现有200次draw不增raster的测试没有覆盖绘制命令数或native Shader更新。
- 全曲geometry及shaping仍在同步remember内编译；Default worker仅准备有界纹理。冷fallback用已测量StaticLayout.draw，仍有成本。两者和设备整机负载需分开验证。
- 旧包SDK28同车30秒歌词播放观察：1092帧，Janky 53.02%，p50 17ms、p90 48ms、p95 101ms。它是宿主整窗数据，含高德和背景，不等于歌词独立耗时；原始证据留在忽略的本机目录。

## 真值与职责

1. Adapter/Store继续唯一拥有录音、可信位置、active/scroll/gap；UI仅在该锚点上纯采样，不新增播放器、计时状态机或伪字符时间。
2. 不可变正文和width/font/metrics决定geometry；同录音升级保留可见锚。采用用户明确的第二种方案：current初始保持正常基线，安全字符按源词区间触发固定1000ms ease-out向上2.5dp，完成后保持稍高位置，不在起点下闪或末端归零。跟随滚动与字符微移分别纯采样，均不改Store游标；保留grapheme／真实ligature／RGBA安全运动边界。
3. 原生完整shaping决定source-word、Bidi/wrap与颜色cell。worker只读布局、用独立paint生成sharp/soft。RGBA决定真实颜色/墨迹和可移动边界；按物理邻接、真实reveal、颜色与相同微移合并绘制批次，完整字形及blank contextual ink保留，不用源码相邻顺序跨过Bidi其它词。
4. 每个纹理持有自己的edge Shader和上次geometry采样；位移/scale未变就不setLocalMatrix。源词渐显只更新真实词前沿；未开唱／已完成的同状态cell合批，活动字符仍按固定窗口采样。每slice统一Canvas变换，批次之间只增量位移，不做逐字save/restore；未映射歌词不能因所有已知词结束被提前唱亮，彩色emoji不能被单色tint。
5. 高频帧由可见墨迹的真实渐显、固定rise窗口和gap共同决定；cursor快照、布局和prepare与帧采样分离。无可见变化时休眠，由下一真实边界唤醒；seek/pause/endpoint/focus/page/lifecycle须验证。
6. cache保留12MiB条目预算、Default/Mutex/cancel checkpoint、有界当前及目标窗口，发布后bitmap不recycle；高频帧不能生成布局、纹理或新的运动状态机。
7. 全曲shaping从同步remember迁到独立Default geometry prepare：正文／宽度／metrics／字体为不可变请求键，逐row检查取消，geometry整体原子发布。请求未完成保留最后匹配文档及其呈现source并冻结，不把新正文cursor套旧layout；完成从旧可见锚迁移，不清空媒体真值、重启录音或阻塞正文获取。离屏取消过期准备，冷首屏按实际编译完成显示，不设人工等待。


## 施工与验收

- 先重构render metadata、批次和edge owner，再梳理frame demand；查明全曲geometry及高频快照的实际边界后按证据处理。
- 验证onset前后稳定基线、源词渐显精确像素、ligature/Bidi/emoji/空白cell/RTL完整性、暂停seek复现、same-recording升级和大seek不空屏。
- 除raster计数外，记录实际draw批次、Shader矩阵更新；未开始／已完成且墨迹运动边界相同的物理连续字符须合批，不能逐字save／restore。活动字符不同位移或连接墨迹保持独立批次，不能为减少计数切碎joining；持续位置帧不得重建geometry或请求纹理。
- 运行相关单测/Lint、三项仓库自检、diff检查和正式同身份签名构建；同车保留数据安装、启动、窗口和日志smoke；同条件30秒整窗数据只作为现场观察，明确歌曲区间及高德负载的可比性限制。
- 产品、架构、代码地图和验证记录更新到当前owner；获取主链做回归保护，不继承历史候选车机性能。
