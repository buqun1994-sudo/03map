# Codex 任务入口模板

涉及高德 APK 静态分析、Smali / 资源施工、重打包、车机运行验证或历史文档整理时，可用以下最小输入：

```text
目标：
当前现象或证据：
允许修改范围：
不能碰的范围：
完成标准：
设备 / 安装 / 签名授权：
文档或交付要求：
```

## 缺字段处理

1. 只读查询、代码地图定位和边界清晰的低风险文档任务，可以基于仓库真值推进。
2. 涉及包名、签名、权限、安装、卸载、清数据、车机写操作、发布或设备数据时，缺少范围或当次授权必须先确认。
3. 用户明确要求只分析、只出方案、review 或不改文件时，不得施工。
4. 完成标准必须同时包含可观察结果和对应验证入口；静态通过不能替代运行级证据。
