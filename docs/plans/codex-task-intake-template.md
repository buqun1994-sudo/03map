# Codex 任务入口模板

涉及高德 APK 静态分析、Smali / 资源施工、重打包、车机运行验证或历史文档整理时，可用以下最小输入：

```text
目标：
当前现象或证据：
相关范围（可选）：
用户明确限制（如有）：
完成标准：
已知设备信息或个人风险（如有）：
文档或交付要求：
```

## 缺字段处理

1. 模板是可选的；自然语言目标足以授权其合理、必要的施工和验证，不要求用户填齐字段。
2. 目标和依赖可从仓库确认时直接推进；仅在缺少必要信息或具体个人风险超出已明确范围时确认，依据见 [安全与密钥边界](../security/安全与密钥边界.md)。
3. 用户明确要求只分析、只出方案、review 或不改文件时，不得施工。
4. 完成标准必须同时包含可观察结果和对应验证入口；静态通过不能替代运行级证据。
