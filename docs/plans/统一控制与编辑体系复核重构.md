# 统一控制与编辑体系复核重构

## 本轮用户确认

1. 内容普通分页仅车辆信息、歌词、投影；应用内控制中心是覆盖层，不是第四页。
2. 空调只具有控制卡与手势展示资格，不进控制中心网格或 Dock；未实现／确认缺失的功能隐藏，临时离线禁用但不永久写成缺失。
3. 车型 JSON 需要承载稳定业务语义与受控传输适配器的声明式读写映射；同类协议换 JSON，新传输协议新增适配器，不运行任意脚本。
4. 控制卡使用现有真实调节能力，列表固定添加项，添加目录在右侧，长按拖入。编辑本身不改变当前卡身份。

## 审计根因

- 目录只集中 ID，JSON 仍强制等于编译后的 iCAR binding，不能真正适配同协议新车型。
- 普通分页仍承载控制中心；气候和未实现功能被作为占位加入候选。
- 编辑层是独立表单／列表副本，不是使用中控件的空间转场；控制卡列表一打开就进入排序，不能继续原卡操作。
- 添加仅短按钮，没有跨候选区拖入；网格高度被固定范围截断，不是正方形。
- 内容多指资格误用于地图单指横向收放门禁。
- 导入选择器暂停时丢设置栏目，实例重建丢请求；有效编辑按钮被静音。
- 编辑重排的焦点／生命周期失效合同弱于现有业务控件。

## 目标架构

### 功能事实

`ControlCatalog` 定义稳定语义、标准呈现与允许展示面；车型配置定义映射、功能声明及初始布局；车辆／系统 Port 提供实际能力与状态；`ContentStore` 统一门禁及用户布局。自检只读、有界，不发送车辆动作；不把离线读失败缓存为能力缺失。

### 编辑事实

布局提交只在接受的 drop／添加／移除／排序时进入 Store。绑定层只拥有一个互斥的 `LayoutSession`，UI 布尔字段仅为投影。控制中心常态、编辑、添加；卡列表常态、排序、添加；Dock 编辑互斥，不允许组合出不存在的状态。

### 画面与动效

- 顶栏始终在遮罩／模糊之上；页面、控制区、Dock 在底层。编辑中的当前控件保留同一业务状态和呈现合同，按真实锚点浮起／回位，不用独立替身表单。
- 四列基础单元按当前可用宽度推导正方形，内边距 20dp，内部间隙 `W/32`；亮度／音量占一列两行。卡片内部尺寸按自身行高适配，避免全屏添加目录放大真实控件。
- 通用拖拽根协调候选区与目标区：长按接管、实时预览避让、边缘滚动、drop 验证、取消回退和弹簧吸附。UI 草稿不冒充持久顺序。
- 抖动单一按需帧钟、稳定 ID 相位；只在编辑存活，位移／旋转在图层阶段读取，不逐帧重组整个页面。
- 添加目录用宿主独立全屏 lease 跟随地图原有几何进度，冻结内容原呈现端点，结束恢复原地图端点；不是歌词全屏动作。

### 导入与设置

系统文档选择器以应用级 journal 恢复待办，返回时恢复配置栏目；系统保留返回任务时可在进程重建后接收，系统丢弃任务时仍可重新进入设置并重选。后台有界读取和严格校验，失败保留旧配置，下次冷启动激活。设置页打开／关闭保留可中断渐隐渐显。Dock 名称默认关闭。

## 验证

先测试编译与定向合同，再相关模块／Lint，再稳定全工程整合及正式签名包。模拟器核验同包身份并查看控制中心常态／编辑／添加、卡片可操作列表／排序／添加、Dock 编辑、设置淡入淡出、导入与冷启动。实车离线，不连接实车；实体服务、真实能力探测、OEM 点击音效与车机帧率单独列为现场项，不借模拟器代验。

## 执行结果

正式源码、共享编辑根与最新真值门禁已完成，补齐候选坐标空间、来源所有权、挂起后代际检查、全屏卡片几何和 Dock 自然高度。五模块 2424 项有效结果（2381 本次执行、43 有效缓存）与 Lint 无错误，最终签名包源码指纹一致，保留数据安装后回拉字节相同。58 份同包模拟器实帧覆盖三页、中心／卡／Dock 编辑及空态恢复、名称、严格 JSON 导入、不热切、冷启动自检缓存、进程重建后返回与重新选择。唯一交付身份、原始报告、实际系统返回边界和剩余实车项见[统一车控与布局编辑验证](<../testing/统一车控与布局编辑验证-20261015.md>)。本轮未连接或操作实车，未执行 Git 提交或推送。
