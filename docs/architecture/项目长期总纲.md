# 项目长期总纲

> **职责：** 当前产品 / 系统范围、正式输入基线和长期不变量。用户行为见 [产品需求基线](../product/产品需求基线.md)，内容区架构见 [内容区主链](内容区主链.md)，源码入口见 [代码地图](../code-map/主链索引.md)，证据要求见 [验证矩阵](../testing/验证矩阵.md)。

## 当前主线

1. 项目面向 iCAR 03 车机壁纸状态下的全屏动态分屏地图导航。
2. 正式输入为高德 `9.5.0.600013`、125% UI、默认全屏 APK；从 `source/amap-9.5.0.600013/` 建立被忽略的施工副本。
3. 启动首帧直接进入展开态：内容层铺满全屏，地图作为右侧固定宽度面板覆盖其上；默认内容区约 `1/3`、地图区约 `2/3`。
4. 历史 `480×480` 悬浮地图已封存，不是当前默认布局、验收尺寸或施工入口。

## 系统边界

1. 复用高德地图、导航、定位和交互能力；不重新实现地图引擎、路网或定位服务。
2. 内容区与高德运行于同一 APK 和地图 Activity 生命周期；不嵌入外部 APK、Activity、WebView 或独立悬浮窗。
3. 地图几何由 `SplitPanelController` 唯一负责；内容区不直接修改 `map_surface`、`ui_surface` 几何。
4. 内容区主题只跟随高德自身解析出的主题状态，不读取系统 `uiMode`，不维护第二套主题开关。
5. 媒体、车况和车控只经统一状态、Port / Adapter 接入；研究文档是车机能力的当前证据源，未经正式应用层读取、命令和状态回流验证的能力不得显示为已可用。

## 正式输入与施工边界

APK 身份、来源差异、快照哈希和施工边界以 [基线清单](../code-map/基线清单.md) 为唯一事实源。本文件不复制版本专属哈希和工具流水账。

- `source/amap-9.5.0.600013/`：只读正式源码快照。
- `apk-work/9.5.0.600013/`：被忽略的施工副本和构建区。
- `apk-archive/9.5.0.600013/`：被忽略的输入 APK 和必要身份材料。
- APK、密钥、设备私有信息、完整日志和截图不得进入 Git。

## 长期不变量

1. 地图收放只改变面板位置，不压缩地图，也不丢失导航 / 定位状态。
2. 地图面板、两条 Surface 和内容层的几何从同一份分屏状态派生。
3. 2D 车首、2D 北上、3D 车首不得因裁剪、Surface 或布局变化产生相机偏移。
4. UI 只消费状态；写操作经命令端口，成功必须由状态回流确认。
5. 新能力沿用既有 Store、Registry、Port / Adapter 和 Renderer 边界，不新建第二套状态或几何主链。
6. 不使用透明 Activity、alpha 为零、延迟搬运或固定缩放级数伪造“启动即分屏”。
7. ADB、电脑常驻连接、root、无障碍和 CAN 不是正式产品运行依赖；正式车控只能通过设备内可验证的车机服务适配器运行，高风险写入遵守当次授权、状态回读和可逆恢复门禁。
