# 项目长期总纲

> **职责：** 当前产品 / 系统范围、正式输入基线和长期不变量。用户行为见 [产品需求基线](../product/产品需求基线.md)，内容区架构见 [内容区主链](内容区主链.md)，源码入口见 [代码地图](../code-map/主链索引.md)，证据要求见 [验证矩阵](../testing/验证矩阵.md)。

## 当前主线

1. 项目面向 iCAR 03 车机壁纸状态下的全屏动态分屏地图导航。
2. 正式输入为高德 `9.5.0.600013`、125% UI、默认全屏 APK；从 `source/amap-9.5.0.600013/` 建立被忽略的施工副本。
3. 启动首帧直接进入展开态：内容层铺满全屏，地图作为右侧固定宽度面板覆盖其上；默认内容区约 `1/3`、地图区约 `2/3`。
4. 历史 `480×480` 悬浮地图已封存，不是当前默认布局、验收尺寸或施工入口。

## 系统边界

1. 复用高德地图、导航、定位和交互能力；不重新实现地图引擎、路网或定位服务。
2. 内容区与高德运行于同一 APK 和地图 Activity 生命周期；不嵌入外部 APK、Activity、WebView 或独立悬浮窗。
3. 地图几何由 `SplitPanelController` 唯一负责；内容区不直接修改 `map_surface`、`ui_surface` 几何。
4. 内容区主题只跟随高德自身解析出的主题状态，不读取系统 `uiMode`，不维护第二套主题开关。
5. 媒体、车况和车控只经统一状态、Port / Adapter 接入；研究文档是车机能力的当前证据源，未经正式应用层读取、命令和状态回流验证的能力不得显示为已可用。

## 正式输入与施工边界

APK 身份、来源差异、快照哈希和施工边界以 [基线清单](../code-map/基线清单.md) 为唯一事实源。本文件不复制版本专属哈希和工具流水账。

- `source/amap-9.5.0.600013/`：从只读输入快照派生、Git 跟踪的唯一可版本化正式源码；原始输入快照固定在提交 `ac6033c`。
- `apk-work/9.5.0.600013/`：被忽略的施工副本和构建区。
- `apk-archive/9.5.0.600013/`：被忽略的输入 APK 和必要身份材料。
- APK 等生成物按现有忽略规则管理；凭据和实际含隐私的证据见 [个人风险口径](../security/安全与密钥边界.md)，脱敏截图或日志摘要可按需入库。
- 施工副本只用于实验；交付前必须将完整可维护改动迁回正式源码，并从正式源码重新构建与验证。

## 长期不变量

1. 地图收放只改变面板位置，不压缩地图，也不丢失导航 / 定位状态。
2. 地图面板、两条 Surface 和内容层的几何从同一份分屏状态派生。
3. 2D 车首、2D 北上、3D 车首不得因裁剪、Surface 或布局变化产生相机偏移。
4. UI 只消费状态；写操作经命令端口，成功必须由状态回流确认。
5. 新能力沿用既有 Store、Registry、Port / Adapter 和 Renderer 边界，不新建第二套状态或几何主链。
6. 不使用透明 Activity、alpha 为零、延迟搬运或固定缩放级数伪造“启动即分屏”。
7. 当前正式应用独立于电脑和 ADB 运行，车控由设备内适配器执行并回读状态。技术方式的选择以实际能力和兼容证据为依据，具体个人风险见 [安全与密钥边界](../security/安全与密钥边界.md)，不按 root、无障碍或 CAN 等名称增设禁令。

## 第三层 Compose 地图宿主（施工登记）

- 正式可维护入口：`source/amap-9.5.0.600013/content-compose/` 保存 UI、Binding 与地图 Compose 宿主 Kotlin／资源；原 `content-src/ContentRuntime.java` 保持高德 Smali 调用签名，改为挂载同一 Compose 呈现。`ui-preview/` 继续作为构建、预览与本机测试工程，编译正式入口，不维护第二份实现。
- 宿主模块：`:map-host`，库 namespace `com.icar03.content.host`，不新建应用身份或 Activity。`ContentComposeHost` owner 负责 ComposeView、必要 Lifecycle／SavedState／ViewModel owner、pause／resume／dispose、内容 viewport；既有 `SplitPanelController` 继续唯一提供地图与分界几何。
- 构建入口：沿用 `scripts/build-content-apk.sh`；Compose／AndroidX依赖必须登记明确版本与完整性，库资源重链接到正式包资源表，多DEX检查重复与闭包，随后原身份签名。包名、版本、minSdk21／targetSdk24及已测试证书不变。
- 目标功能只来自第二层既有正式Port；不启用预览数据／场景开关，不扩展未声明功能。第三层建立时只构建与本机验证，用户自行上车实测，该轮未连接或写车机；这是历史执行范围，不限制后续用户任务。

## 第二层 Compose 能力接入

- 源码目录：`ui-preview/content-runtime/`，namespace `com.icar03.content.runtime`，Android library，不新增应用包名；第一层预览 `:app` 不依赖本模块，保持纯模拟。
- 组件 owner：`ContentUiMapper` 仅投影正式快照；`ContentBinding` 订阅调用方唯一 `ContentStore` 并将用户意图送回既有端口；`BoundContentPanel` 绑定宿主生命周期与真实媒体封面。Shared 默认不销毁 Store，Owned 只能接管唯一生命周期；主题仍由原宿主向 Store 提供高德真值。
- 能力边界：只接已有车辆读数、四项控制、媒体及五来源、系统亮度／音量。未声明能力不扩端口，歌词仅空态、设置仅触发反馈；不把第一层占位卡变成新功能。
- 复用边界：Gradle 精确白名单直接编译正式 `content-src/` 八类最小闭包，不复制 Adapter、不编译旧 Renderer／ContentRuntime；正式源码只增加必要的注入构造、能力声明与系统权限声明，默认创建真实 Adapter 的入口保留。
- 验证入口：`:content-runtime:assembleDebug`、`:content-runtime:testDebugUnitTest`、`:content-runtime:lintDebug` 及第一层回归。第三层高德 APK 注入、签名构建和实车闭环不在本轮，不能以 AAR / 模拟状态宣称已经替换高德页面。具体能力与证据见 [第二层验证记录](../testing/Compose第二层能力接入验证记录.md)。

## 独立 Compose UI 预览层（2026-09-30 登记）

- 源码目录：`ui-preview/`，独立 Gradle 工程，`:app` 为预览宿主，`:content-ui` 为可复用 Android library；不替代或修改高德正式源码入口。
- 独立应用身份：`com.icar03.content.preview`；库 namespace 为 `com.icar03.content.ui`。这是新增预览身份，不是高德改包，不使用高德签名或权限。
- 组件 owner：`:content-ui` 的 `ContentUiState` / `ContentEvent` 负责纯模型契约，`ContentPanel` / `ContentTheme` 负责无业务依赖的 Material3 呈现；`:app` 的 `PreviewController` 唯一负责模拟数据、场景与异步任务，`MainActivity` 负责生命周期。真实 Port / Adapter、地图与车辆能力不在本层实现。
- 视觉边界：本预览的第一层浅色默认态按用户提供的 640×1080 原型构图实现：四列卡片网格、顶部温度／时间／续航关系、纵向亮度／音量分段控件、一体式横向媒体卡和 Dock。组件使用 Compose Material3/Foundation 的可组合基础能力，外观由本地令牌覆盖；不把 Material 默认页面、横向 Slider、NavigationBar 或营销说明作为设计基线。本轮增加局部向下柔和阴影、80dp媒体热区及12dp间隔、同构图中性炭黑深色候选和原厂夜间座椅资源；原厂图标累计40项均可溯源。双主题关闭／展开截图已实际查看，媒体来源区96×120dp，右上方锚定浮层宽200dp、五行各80dp，本机几何和来源交互已验证；目标车机密度／触感和真实能力仍待后续确认。中文采用 Android 系统 sans-serif fallback。
- 验证入口：在 `ui-preview/` 执行 `./gradlew :app:assembleDebug :app:testDebugUnitTest :content-ui:testDebugUnitTest`；Android Studio 打开该目录运行 `ContentPanel` 的 Compose Preview。场景和可选 Robolectric 截图入口见 `ui-preview/README.md`。仅本机验证，不连接设备、不执行真实车控、不宣称集成已完成。
