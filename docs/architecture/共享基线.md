## 3. 本项目的执行翻译

1. 用户只描述目标和可见结果，AI 负责调用工具完成解包、修改、构建、安装、启动和取证。
2. 原始 APK 与设备输出是输入证据；修改前保留只读原件，修改后使用独立工作副本。
3. 每次结构性修改后先做最小静态检查，再进入下一步；构建通过后必须继续安装、启动和观察窗口行为。
4. 失败时保留第一现场和完整错误类别，修复根因后重新构建和验证；不靠扩大权限、清数据或忽略校验让流程“看起来能跑”。
5. 只有用户明确授权的高风险动作才执行；无线调试断开或系统弹窗需要用户时，暂停在具体步骤，不让用户重新手工走完整流程。
6. 新的稳定规律写入本项目文档；如果规律适合所有项目，先链接或回流到共享模板，不在本项目复制一套互相漂移的总规则。
