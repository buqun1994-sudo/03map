# 共享上下文与人机协作基线

本项目已将跨 03 系列可复用的方法落地为 .agents/skills/ 下的 rule-discovery、skill-authoring、task-closeout 和 template-feedback；高德版本专属入口由 amap-code-map 维护，内容区视觉审计由 redesign-content-panel 维护。来源、去专有化范围和未采用资产见 03系列协作资产提取记录。

## 1. 目的

`03地图` 直接复用 `03lyrics` 已经验证过的上下文读取、源码真值、分层施工、主动验证和收尾表达方式。链接仅作方法来源参考，不自动继承 `03lyrics` 的限制、授权门槛、应用身份、歌词业务、包名或 UI 规格。

## 3. 本项目的执行翻译

1. 用户只描述目标和可见结果，AI 负责调用工具完成解包、修改、构建、安装、启动和取证。
2. 原始 APK 与设备输出是输入证据；修改前保留只读原件，修改后使用独立工作副本。
3. 每次结构性修改后先做最小静态检查，再进入下一步；工程行为改动构建通过后按任务范围继续安装、启动和观察窗口行为；纯文档任务只做相应检查。
4. 失败时保留第一现场和完整错误类别，修复根因后重新构建和验证；权限、数据和身份变化按实际原因处理，不用它们掩盖尚未解释的失败。
5. 具体个人风险超出已明确目标时才按 [本项目风险口径](../security/安全与密钥边界.md) 确认，已有授权不重复询问；无线调试断开或系统弹窗需要用户时，暂停在具体步骤，不让用户重新手工走完整流程。
6. 新的稳定规律写入本项目文档；如果规律适合所有项目，先链接或回流到共享模板，不在本项目复制一套互相漂移的总规则。
