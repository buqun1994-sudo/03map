# 歌词与封面统一解析

正式入口仍是 `ContentMediaAdapter → ContentStore → ContentLyricsEngine → ContentPorts.LyricsSnapshot`，播放时间线归 Store，不由来源或图片任务创建。03lyrics 的公开媒体仲裁、录音 proof、取消及人工优先契约已只读对照；本轮只修改03地图，不建立运行时跨仓源码依赖。通用注册、调度、格式、证明接口留在正式运行库，可在独立版本化模块中复用；UI、授权Cookie与Android缓存是宿主适配。

## 来源与所有权

[来源注册](../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/LyricsProviderRegistry.kt)集中定义LRCLIB、QQ、网易、酷狗、酷我、咪咕、汽水和Apple Music八个Provider及能力。Apple注册在主链，当前没有登录界面，默认不可用并在调度前跳过；不会进行开发者令牌bootstrap或阻塞国内回退。Musixmatch、LyricFind、Deezer、AMLL联网来源仍不启用，TTML格式支持与AMLL来源分开。

[来源合同](../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/LyricsSource.kt)分为目录候选、基础正文、可选增强和封面资源。Provider只负责协议、格式及短命资源上下文，不写自动缓存、不决定当前歌曲、不拥有播放时钟。原始目录snapshot和sourceId不能被基础/增强响应改写；所有可用结果仍经过候选selector与proof重放。咪咕未知duration保持0，不能用当前播放时长补成可准入候选。

[SharedProviderCatalog](../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/SharedProviderCatalog.kt)按Provider、授权/地区revision和请求共享目录IO及30秒有界内存结果；最多128项成功结果，没有凭据、歌词正文或图片。歌词与封面分别订阅，截止和取消独立，最后一个订阅取消才断开生产HTTP。错误及迟到结果不缓存；登录/地区变化不会命中前一账号目录。异步订阅回调不占用网络线程等待另一调用者；独立定时器关闭超时订阅，close与提交并发以取消/失败终态结束。

[LyricsProviderExecutor](../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/LyricsProviderExecutor.kt)有8个工作线程，队列优先级为基础正文、封面详情、目录、可选增强。同请求正文最多2路、封面详情最多2路、可选增强1路；图片另由Engine最多2路解码/下载。默认先启动两个国内来源及LRCLIB精确查询，350ms后扩展回退；每个消费者目录同时最多3路。目录命中元数据后暂停查询变体，得到可用正文/纯音乐才结束该源；正文和增强均失败会恢复余下变体，重复空ID不能再次把来源锁住。

## 渐进显示与身份

QQ/网易/酷狗/酷我/咪咕先返回真实逐行轨，再请求独立QRC/YRC/KRC/LRCX/TRC/MRC；同HTTP已经返回的有效附轨直接保留。空逐行而真实逐字有效的路径仍可用；附轨失败不能清空有效主轨。来源私有上下文按完整候选有界缓存，accessKey/session/用户token不进入结果、proof或SQLite。

[LyricsResolutionSession](../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/LyricsResolutionSession.kt)实际使用1800ms单次目录截止，整体质量预算20秒。首个合格同步正文通过渐进回调发布；后续真实逐字/译文等质变也立即回调，不等待所有慢目录完成。同能力档、仅来源/分数变化不替换当前正文。Engine缓存异步落库，事务内重读人工winner；生命周期、录音generation、查询revision和proof四层检查仍有效。

[DirectLyricsRepository](../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/DirectLyricsRepository.kt)歌词和封面使用同一SharedProviderCatalog及同一组Provider。当前录音专辑和时长已知时，独立验证候选即发布已有URL，缺图才补选定ID的详情；未知专辑或时长仍等目录闭合，保留完整批次同发行歧义门禁。目录总窗口3500ms、URL/详情窗口6500ms；返回完整列表只用于兼容，不再挡住候选流。

[ContentLyricsEngine](../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/ContentLyricsEngine.kt)原生图优先，缓存先显示，最多4个唯一URL、最多2个下载lane；图片成功立即发布并取消查询/其它下载，原生图迟到同样抢占。搜索、详情、图片和有限重试共用9000ms预算；已尝试的坏URL不反复整轮重搜。2MiB图片响应、512px解码、未发布过期Bitmap回收与已发布Bitmap不recycle规则保持。歌词与图相互独立推进，封面失败不回滚歌词READY，图片替换不重置时间线。

缓存同库1GiB和人工保护保持。自动质量版本升到2以触发旧策略条目的一次后台重评，普通刷新仍六小时/最多三次有效Found；失败不计数。偏好/登录revision变化通过Flow主动通知，暂停时不需要新媒体事件；保留现有正文和封面，强制一轮歌词与封面后台验证，即使图缓存已命中也继续新Provider检索，人工歌词条目和原生图仍直接优先。耗时日志使用单调时钟，来源search/body的排队时间纳入，记录阶段和来源，不记录歌词、URL或凭据。

## 设置页后续接线

颜色/按压、页面布局仍位于UI层，本轮未修改。UI通过runtime/host绑定以下facade，不能令低层content-ui直接依赖content-runtime形成循环：

- [ContentLyricsPreferences](../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/ContentLyricsPreferences.kt)：`getPreferredPlatform()` / `setPreferredPlatform(Platform)`，包含AUTO及8个Provider。独立私有偏好命名空间，生产资源已读取；影响歌词和封面首选调度及同能力排序。未知蓝牙不猜手机平台，不改变原厂媒体来源仲裁。
- [AppleMusicConnection](../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/AppleMusicConnection.kt)：公开`state`、`revision`、`prepareLogin()`、`LoginAttempt.loginUrl`、`pollOfficialLoginCookies()` / `acceptCookies()`、`cancelLogin()`和`disconnect()`。设置页创建WebView并展示官方登录URL，登录期间才读Cookie；页面关闭停止检查并cancelLogin。后端已有重连先清旧Apple Cookie、旧attempt拒绝、域校验、8秒itua宽限、过期/拒绝/撤销隔离。没有设置页时保持DISCONNECTED。

Apple复刻的实际参考是[AppleMusicConnection.swift](https://github.com/Yudaotor/lyrimuse/blob/e71fc2da2df14f1e7b9f8e6d49d65080b52dd5d2/lyrimuse/Sources/lyrimuse/Settings/AppleMusicConnection.swift)及[applemusic.go](https://github.com/Yudaotor/lyrimuse/blob/e71fc2da2df14f1e7b9f8e6d49d65080b52dd5d2/lyrimuse-collector/applemusic.go)。用户在官方页面登录，media-user-token保存在AndroidKeyStore AES-GCM加密的应用私有存储，状态不含token；没有用户凭据时零网络。公开developer bearer来自官方JS bundle并校验，单bundle上限4MiB，API/歌词仍2MiB；没有要求用户提供开发者私钥。未知storefront用`/v1/me/storefront`补全，不猜us。认证请求只发官方API域且禁止跨域redirect。

Apple目录时长/标题/歌手/专辑按真实字段，`/lyrics`先提供逐行TTML，再`/syllable-lyrics`提供真实词轴及localizations；保留真实agent/BG，封面CDN请求512px而非桌面全图。401/403标记当前用户凭据失效，旧请求不能拒绝新登录；普通404是该资源无词。后续设置页接上官方登录即可进行账号/订阅与地区的真实测试，本轮无有效用户凭据、不宣称Apple在线验收。
