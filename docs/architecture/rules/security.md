# 安全规则

1. 真实 APK、签名材料、设备地址、日志和截图只存在本机临时区，不提交 Git。
2. 第三方 APK 的修改必须有合法测试权；不以本项目文档承诺绕过服务端授权、账号校验或商业许可。
3. ADB 是开发和取证工具，不是正式运行依赖；正式应用不依赖 root、无障碍模拟或电脑常驻连接。
4. 车控属于正式产品能力，必须通过 `VehicleAdapter` / `VehicleCommandPort` 接入；研究文档中的已验证服务、Binder 或 `CarPropertyManager` 路径可以作为适配器输入，页面层不得直接写厂商属性或 Binder 事务。
5. 不连接 CAN，不使用 root 或无障碍绕过系统权限；任何车控写入都要有当次授权、可控车辆状态、状态回读、可逆恢复和最小日志证据。
6. 发布或分享前必须重新检查 APK 来源、许可证、签名身份、隐私数据和第三方服务条款。
