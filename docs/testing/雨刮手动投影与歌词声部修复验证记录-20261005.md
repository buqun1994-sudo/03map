# 雨刮手动投影与歌词声部修复验证记录（2026-10-05）

## 范围与实现

本轮仅修复手动雨刮的UI投影、歌词身份／左右位置及验证中复现的既有词轴重挂失败；用户明确允许顺手修复发现的问题。不新增车辆状态、歌词时钟、别名服务、缓存迁移或获取流程。

- 雨刮：[ContentModels](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/ContentModels.kt#L63-L71>)从唯一displayed派生手动显示：0关闭、1..4手动、5自动只在手动图标上下文映射0，unknown不改；[ContentPanel](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/ContentPanel.kt#L359-L401>)两入口仅1..4选中，自动按钮仍消费原始5。actual、target、pending、确认记忆和Vehicle事件／协议保持。关闭↔自动不重播手动图标，也不出现手动A标或开启着色。
- 歌词：[LrcSpeakerLayout](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/LrcSpeakerLayout.kt>)先复用录音owner的成员拆分／归一识别完整歌手身份，再建立独唱首次出现的左右顺序；去除短名字、空格和连字符门槛，保留未知名字重复证据和普通冒号保护。制作／选段不登记为人，联合标签和合唱靠左，不占solo序号；marker-only行切换继承身份但不绘制。[TtmlSpeakerLayout](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/TtmlSpeakerLayout.kt>)仅单agent非group行建立顺序。首个真实独唱左、第二个右。
- 呈现：[LyricInkRenderer](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/LyricInkRenderer.kt#L187-L227>)不再有居中列、居中对齐或中轴pivot；遗留Center值按Leading绘制，不重编号旧边界。默认无声部正文宽度保持。
- 顺手修复：[LrcParser](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/LrcParser.kt#L143-L234>)的正文key复用既有normalizeText，以兼容标点／大小写差异；常规对齐与可信重挂都只剥LrcSpeakerLayout.identify已认可的标签，普通冒号全句参与比较。两原始流独立统计重复证据，不因跨通道重复而虚增；正文key须非空，双方已认可的声部不能相互矛盾。删除Parser重复的纯冒号身份猜测，由现有[LyricsContent](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/LyricsContent.kt#L23-L24>)传入同一候选元数据。可信重挂保留YRC-only身份，译文／音译先附旧轴再随正文走，真实词区间及原始缓存不改。纯标点空证据（近轴及重挂）、乱序、缺行、错误正文、非法区间与未知曲长仍拒绝；`A/B`未确认各成员时不能压平冒充独唱`A-B`。

03lyrics只读对照确认合作分隔符不包含横杠、无短名字上限、raw缓存和cancel边界可复用；其现有overlay不含地图多人位置解析，故不借其测试作为本轮布局验收。
