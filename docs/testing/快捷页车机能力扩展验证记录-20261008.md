# 快捷页车机能力扩展验证记录（2026-10-08）

## 结论

13 项快捷页车机功能已沿 `ContentStore → ContentBinding → ContentUiMapper → ContentPanel` 与 `ContentVehicleAdapter → ContentVehicleProtocol` 主链落盘。请求包、pending 目标、实际回读、unknown、拒绝、断连和超时保持分离；新增入口不进入 `DockShortcuts.items`。副驾电动调节因方向／轴／停止值没有证据，保持不可用且不发送 Binder 写；清洁屏幕是宿主全屏遮罩，`597/0x255=11` 只作 P 挡门禁。

实体车辆动作尚未执行，下面的“通过”均表示源码、替身服务或签名包静态证据，不能替代车机现场成功。
