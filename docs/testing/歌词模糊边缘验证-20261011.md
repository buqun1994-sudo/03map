# 歌词模糊边缘验证（2026-10-11）

用户反馈普通分屏及沉浸全屏的非当前歌词模糊在左右出现硬截断。本轮只修复共用绘制入口，不调整排版或模糊配方。

## 根因与修复

[WallpaperLyrics](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/WallpaperLyrics.kt#L108>)的外层`clipToBounds()`已按实际歌词视窗裁剪；`requestedInset`和`width`负责48dp×场景比例的排版留白。原native绘制又在`[inset, width-inset]`硬裁剪，切掉模糊进入留白的部分。

正式修复仅移除这条内缩裁剪并添加职责注释，原`translate(inset, 0)`、测量宽度、字体、行高、滚动锚点及纵向edge shader继续使用。外层真实视窗、Pager及宿主裁剪保留，模糊自然进入页内留白。原[LyricInkRenderer](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/LyricInkRenderer.kt#L485>)已经用`extractAlpha`的offset和完整位图尺寸外扩soft bounds，非当前行直接画整个soft rect；本轮没有改动字形栅格、逐字单元或位图密度策略。现有注音等未提交改动保留。
