# 设置偏好重构与车机密度验证记录（2026-10-05）

## 范围与唯一 owner

本轮按用户要求重构正式 Compose 设置页。设置只提供14项可保存的呈现偏好：顶栏星期／秒数／温度／电量／充电信息，歌词字号／句间距／声部布局／当前行强调，封面氛围，媒体来源入口，Dock数量，界面透明度和操作结果提示。车辆状态、车控、亮度、音量、播放和来源选择继续由快捷页或媒体卡拥有，设置详情不重复这些入口。

设置事件沿 `ContentEvent → ContentBinding → ContentStore → ContentPreferenceStore` 保存，`ContentUiMapper` 投影到同一个 `ContentUiState`，实际消费者仍是 `ContentPanel`、`LyricsBodyTransition → WallpaperLyrics` 和 `BoundBindingPanel → MediaAmbientBackground`。当前页面 ID 继续恢复上次页面，未冒充独立启动页偏好；打开状态、选中设置分组、待确认目标和提示不持久化。

## 行为与密度规则

| 项目 | 本轮实现 |
|---|---|
| 设置分组 | 顶栏、歌词、封面氛围、媒体、Dock、交互；所有项有实际消费者 |
| 原子行 | 完整行可点击，最低78dp且不少于88px；主文字至少24px、辅助文字至少16px；详情宽度小于280dp时开关移到文字下方，保留完整名称 |
| 选项 | 最低56dp且不少于64px高；按可用宽度以至少64dp且不少于64px的列宽换行，避免把最后一项挤到不可见区域 |
| 菜单 | 宽屏152dp、中屏144dp、窄屏112dp；只显示居中标题，菜单和详情分别纵向滚动，切换分组重置详情滚动 |
| 手势 | 整段顶部手势带，紧凑72dp、常规92dp；浮动面板底边与媒体卡底边对齐，左右边界与Dock对齐，详情只负责滚动 |
| 开关设置页 | 设置按钮打开／关闭同一页；退出过程中保留门禁，允许设置按钮中断退出重新打开 |
| 歌词 | 字号调整全部轨道；句间距调整真实行槽padding，段内自然行高保持；声部开关只投影已有行位置；关闭当前行强调仍使用同一可信播放游标 |
| 封面氛围 | 关闭取消烘焙并释放氛围引用，媒体卡封面保持；拒收关闭前的迟到worker结果，开启后按当前封面恢复 |
| Dock | 3／4／5／6项，车锁固定首位、设置固定末位；中间项按既有顺序裁剪，不改变快捷页清单 |
| 提示 | 关闭立即清理当前消息与计时器，隐藏期间新提示被丢弃，开启不回放旧失败；真实命令仍按原确认链运行 |
| 存储 | 保留旧`content_preferences_v1`容器并写`preferences_version=3`；v1缺项取默认；坏类型／NaN／Infinity／越界按单项回默认，界面透明度限制20%至100%，旧ID与五槽Renderer兼容保持 |
