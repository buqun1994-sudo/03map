## 4. 设备与性能边界

最后执行`node scripts/find-vehicle-adb.mjs --serial-only`实际exit1：393ms并发扫描253个TCP5555地址未找到S56_HQX/SDK28。随后`adb devices -l`为空。没有沿用旧IP，没有安装/卸载/清数据/地图启动/车控写入/日志采集。

故本轮未测真实新歌首句/首词/首图耗时、网络可达性、车机KeyStore/CookieManager或订阅账号地区。1.8秒目录、20秒质量回合、6.5秒候选和9秒图总预算是代码调度界限，不是现场响应承诺；用例验证的是不被慢阶段挡住及取消正确，不将720项测试或门控超时换算成速度倍数。
