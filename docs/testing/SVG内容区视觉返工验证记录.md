# SVG 内容区视觉返工：本机验收记录

> 本记录只对应本轮从正式 `source/amap-9.5.0.600013/` 重建的签名候选；[上一候选的视觉失败记录](SVG内容区复刻验证记录-20260928.md) 原样保留，不把旧包测试或实机证据归给新包。`Group 77.svg`／`Group 78.svg` 是完整参考画面，不进入 APK。

## 2026-09-29 深色调色板修正

用户反馈上一版深色背景不够黑且带蓝灰偏移。本轮仅在 `ContentTheme.dark()` 收敛呈现令牌，不改变地图 Surface、分屏几何、状态 owner 或高德日夜真值链：背景固定为 `#0F0F0F`，普通表面为 `#1A1A1A`，提升层为 `#232323`，选中层为 `#2D2D2D`，按下层为 `#414141`；文字、分隔线和状态色同步降饱和，宿主测试固定校验暗到亮的层级顺序。新的签名包与 `golden-dark-shortcuts.png` 路径、哈希和测试结果在本记录末尾补齐。

## 2026-09-29 交互返工补充

本补充覆盖用户本轮提出的顶栏、主题重入、座椅连续点击、系统滑条、阴影、媒体来源弹层、按下热区和长按行为；它更新本记录中与这些行为冲突的旧表述，上一轮视觉基线和原型差异仍保留作历史对照。

1. `ContentRenderer` 现在以高德同包 `Roboto-Regular.ttf`／`Roboto-Bold.ttf` 绘制内容；顶栏温度／时间／里程恢复原字号，仅提高为 Bold，温度取整，里程只显示原始数值，不追加 `km`；来源弹层改为统一 `88×88px` 正方形热区＋居中文字的竖向布局。
2. 快捷卡、系统滑条、控制卡、媒体来源按钮和 Dock 底座统一走 `DownwardShadowDrawable`；媒体播放、下一首、来源、快捷卡和 Dock 共用 `bindPressEffect()`，按下背景使用 `PRESS_CORNER_PX=24` 的高圆角矩形，来源常态无固定背景。滑条文案移到图标下方，百分比填充按底部到顶部计算。
3. `ContentRuntime` 以高德 `GAdaAndroid.onDayNightChange(I)` 回调和 `nativeIsNightMode()` 读取为主题真值，不保存主题偏好、不读取系统 `uiMode`，attach／resume 只重新读取高德值。
4. `ContentStore` 连续车控点击使用 pending 档位作为下一次计算基准；点击先发布目标 UI，再异步调用 `ContentVehicleAdapter`，按摩开启在发送 `0x243` 前确认 `0x241=2`、模式／强度有效，快照只用于确认、失败和日志。Dock／快捷项长按当前明确不打开编辑列表，编辑态留待后续需求。
5. 最新正式源码构建与签名命令为 `bash scripts/build-content-apk.sh`；最终签名包已重新生成，并用 `bash scripts/test-content-host.sh <signed.apk>` 完成 **19 项**宿主闭环和视觉帧采集。本轮补充三类座椅在旧快照未回流时的 `3→2→1→0` 连点、主题回调、来源按下态清除、媒体／下一首／Dock／快捷统一按压态回归；车机发现失败，真实主题回调、驾驶视距和车控写入未冒充实机通过。

## 对照结果

| 区域 | 原型 → 新宿主画面 | 结论与剩余差异 |
|---|---|---|
| 顶栏 | 时间锚定内容区 x=`320`；左温度、右里程＋电池同排 | 中心实测约 `319–320`，在 `≤4px` 门槛内；里程只显示原始数值，未知为 `--`，无“续航”字；温度按整数显示，温度／时间／里程恢复原字号并使用高德 Roboto-Bold。宿主样本温度、时钟时刻、演示电池色与原型不同，不以示意数字做像素匹配。插枪／预约／充电的单排状态、状态先于里程及长文本不碰撞由自动化覆盖，非车机真实回流。 |
| 快捷卡／滑条 | 首排四列左缘 `20/175/330/485`、卡 `135×135`；高条 y=`214`、高约 `290` | 座椅通风／加热／按摩均为**真实**多状态按钮；亮度和音量才使用纵向系统滑条。原型的第二行及后续重复座椅卡只是排版占位，因此下方留白不添假按钮。宿主样本第二张卡为白底选中态；原厂图标与真实不可用／关闭状态取代原型占位图形。 |
