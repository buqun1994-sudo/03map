# 歌词页面媒体区细化定向验证（2026-10-06）

本轮只细化上一轮已经完成的全屏媒体布局，未生成 APK。用户要求在设置项相关施工完成后统一打包，因此本记录只保存本轮正式源码改动与隔离基线上的 content-ui 定向证据，不把本机帧或本轮测试写成最终签名包／车机结论。

## 施工内容

- [ContentPanel.kt](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/ContentPanel.kt>) 的 `ImmersiveMedia()` 用同一可用正方形边长测量封面槽和媒体区，移除封面独立的 `90%` 缩放及 `420／480dp` 独立上限；横向候选仍为内容宽 `88%`、上限 `560dp`，垂直不足时封面与媒体区同步缩小。
- 封面到媒体区间隔调整为紧凑 `32dp`、常规 `40dp`，歌曲／歌手、真实进度与时间、控制按钮依次纵向排列；控制按钮位于进度条下方居中，按钮间距恢复为紧凑 `14dp`、常规 `20dp`。
- 播放／暂停、下一首、媒体来源共用一个尺寸：常规 `84dp`，普通紧凑 `72dp`；固定 `1920×1080`、高密度矮内容区在高度约束下使用 `52dp`，仍保持三枚按钮与可见按压面统一，不让最后一枚被 Row 约束压缩。
- `RoundedPressButton(pressAreaSize)` 只为沉浸媒体按钮开放按压面尺寸参数，普通媒体卡、Dock 和快捷控件继续使用既有默认按压尺寸。暂停／播放仍保留 `.76→1.0`、350ms、原 `CubicBezierEasing(.32,.72,0,1)`，仅在 `graphicsLayer` 读取缩放值。
