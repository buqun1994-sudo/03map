# 静态封面背景与快速打包验证（2026-10-09）

本轮按用户要求移除模糊封面背景的持续运动、逐帧时钟及10Hz周期烘焙／发布，只做背景相关定向检查并快速构建签名包，车机由用户手动测试。上一轮45／55收放与前45%建立全屏背景的修改同时进入本包。

## 当前实现

[MediaAmbientBackground](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/MediaAmbientBackground.kt>)删除`while (isActive)`／`withFrameNanos`背景循环、100ms采样间隔、运动相位及发布相位；`AmbientSceneBaker.prepare(artwork, dark, viewport)`没有时间参数。只在封面、主题、生命周期恢复或实际烘焙几何变化时准备静态端点；稳态没有持续生成或发布背景帧。原确定种子初始构图固定为静态pose，保留overscan、三层柔光与高德双主题可读性遮罩，worker最长边仍192px。

[ArtworkProjection](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/ArtworkProjection.kt>)保留一次性6×6取色、128px柔化色场、灰度中性及空间颜色；pose移除周期参数。[BoundContentPanel](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/BoundContentPanel.kt>)不再传入播放动效开关，[ContentPanel](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/ContentPanel.kt>)删除背景运动的设置遮挡门禁；暂停／恢复、窗口焦点或设置开合不会启动背景采样。歌曲身份、封面到达前保留旧色场、无封面主题底色、失败准备与request／generation拒旧仍沿原owner。

保留封面出现／新图替换／确认非歌曲消失的500ms柔和过渡，从实际混合颜色与opacity继续，中断不闪黑。保留地图收放的45／55前景节奏、固定fullSize背景裁切及双向交接；[AmbientPresentationScene](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/AmbientPresentationScene.kt>)删除无用motion phase字段。歌词跟随／微动态和播放封面缩放仍属原有功能。
