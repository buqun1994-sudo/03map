## 原厂清洁调用的适用边界

研究已确认三种原厂 owner：SystemUI 内部覆盖、原厂设置内部按钮和导出的 SmartScene Activity。最终采用研究中已完成普通 UID 全屏调用／短触／正常长按退出闭环的 SmartScene 路径；不能继续用“SystemUI 无 Activity resolver”推断它无普通应用入口。

正常长按倒计时完成先设 `isExit=false` 再 `finish()`，跳过退出洗车命令。外部打断时仍为 true 的 `onStop()` 分支，以及原厂 Application 冷启动的残留场景恢复行为，以[研究记录](<../research/车机控制能力扩展研究-20261008.md>)为准；本轮正式地图验证只测正常长按退出，不主动制造残留场景或外部打断。该原厂 Activity 不能被描述为禁用所有其它独立悬浮层。`screen_clean` 不是统一窗口状态，宿主不写该设置制造入口。
