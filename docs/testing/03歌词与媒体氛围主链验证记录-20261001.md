# 03歌词与媒体氛围主链验证记录（2026-10-01）

## 本轮结论

正式源码已把03歌词的解析、候选准入、proof缓存、内置LRC、可信时间线和封面回退接入现有唯一主链：`ContentMediaAdapter → ContentStore → ContentBinding / ContentUiMapper → Compose`。页面不创建第二个歌词Store，不使用WebView、悬浮窗、无障碍或新的播放owner。

歌词有数据时由 `WallpaperLyrics` 直接绘制在内容区中间留白的透明视窗；空数据仍显示“暂无歌词”及现有来源入口。播放中且进度未知只预览首句，暂停保留已显示句；可信位置更新才推进当前句。播放中的真实封面同时进入媒体卡和 `MediaAmbientBackground`，后台生成80×80色场，API28兼容Canvas网格缓慢流动；暂停、切歌、无封面和生命周期停止会清除或释放自有氛围位图。
