## 输入与职责

[正式源码](<../../source/amap-9.5.0.600013/>)由高德 9.5／125% 输入基线派生，最终源码指纹为 `08cf78b0510217c2f36f85fe40f1147c3e74653d6babeb6cf9ff344ab599d44c`。地图几何和吸附仍由原 `SplitPanelController` 负责，UI 消费地图 progress。歌词保持唯一正文／时间线 owner：自动跟随使用可见窗口内逐组延迟；DOWN、手动拖动、暂停、页面／模态／后台状态停止自动运动，真实 seek 可立即重定位。歌词页面动作浮层由祖先空白点击观察与实测按钮行边界共同拥有，显示租约为3秒；歌词设置事件直达 Lyrics。

歌词沉浸态由同一 `LyricsBodyTransition` 内容实例移动到宽端点，左侧约1/3保留封面、曲名和播放／下一首／来源控制，右侧约2/3放大歌词。播放封面缩放为1.0，暂停为0.76，原媒体卡在沉浸态隐藏。顶栏和 Dock 独立受偏好控制，默认显示，沉浸 Dock 为透明层。页面空白点击显示退出动作，Back／地图恢复返回分屏。

背景稳态保留原小屏 crop、aspect 和 viewport。转场捕获当前实际混合画面，包括在实际主题背景上的淡入强度，再准备 compact bridge 与 wide endpoint；运动相位按请求固定，最多绘制这两个端点。已经发布的位图只释放持有引用，不主动 recycle，以免已提交绘制帧或取消中的 worker 仍在使用。准备结果只确认原进入代数；相同场景复用也会确认本次进入请求。地图端口重绑、宿主停止和新请求会隔离旧结果。

3. 从歌词页打开设置，确认 compact 入口直达 Lyrics；空白点击显示动作，三秒后消失，子控件点击／纵向拖动不误触发。连续进入、退出、再次进入沉浸，核对左1/3媒体、右2/3歌词、Cover 1.0／0.76、透明 Dock、原媒体卡隐藏和 Back／退出动作。
