## 唯一布局职责

[LyricSpeakerLayout](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/LyricSpeakerLayout.kt>)接替两格式各自的布局准入与位置算法，位置常量仍为0／1／2／旧3，不改端口序号。它只消费已经认可的实际正文身份，在正文解析／投影时执行，不进入热帧。

- [LrcSpeakerLayout](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/LrcSpeakerLayout.kt>)保留原成员拆分、完整名字识别、未知身份重复证据、标签切换及附轨清理；先移除纯标签行，再按实际保留正文交共用规则。只有标签没有独唱正文的名字不占顺序，也不虚构第二个独唱。
- [TtmlSpeakerLayout](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/TtmlSpeakerLayout.kt>)仅提取实际agent引用及group声明，删除其独立位置算法；联合引用不变成两条独唱证据。
- 实际正文不足两个独唱身份，整曲输出Unspecified；只有合唱／旁白／联合或单独唱＋合唱也保持默认。两个以上才按首个真实独唱左、第二右，shared靠左且不占solo，未标记行继承已成立的布局位置。

[默认排版](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/LyricInkRenderer.kt#L178>)原本已对Unspecified返回0／0声部缩进；[WallpaperLyrics](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/WallpaperLyrics.kt#L94>)仍扣左右各48dp作为整行可用宽度。两处生产代码均未改；不增加第二套渲染、绘制末尾特殊裁剪或UI猜测。主文／译文／音译／背景轨仍共享同一行几何，测量、纹理和绘制一致。单声部默认行复用已有投影对象；词轴、原raw缓存、录音身份和生命周期保持。

## 回归与原生帧

[跨格式载荷合同](<../../ui-preview/content-runtime/src/test/java/com/icar03/content/runtime/lyrics/LyricSpeakerLayoutContractTest.kt>)以LRC及TTML实际解析入口覆盖普通、单独唱、纯合唱、单独唱＋合唱、只有联合、有效两独唱及无标签继承；即使歌手／agent元数据声明两人，不能替代正文声部证据。单声部YRC明确检查身份、每个词原起止时刻及译文／音译保留。[纯标签回归](<../../ui-preview/content-runtime/src/test/java/com/icar03/content/runtime/lyrics/LrcSpeakerLayoutTest.kt>)检查只有标签不启用布局，以及实际第二独唱出现后按真实正文顺序分配。

[原生宽度回归](<../../ui-preview/content-ui/src/test/java/com/icar03/content/ui/LyricSpeakerLayoutRenderTest.kt>)在API28／34的640px画布保留左右48px，选取一条默认544px可用宽度能单行显示、声部窄列会换行的合成正文；检查所有轨道的完整默认宽度、正文确实超过左声部边界且不侵入原边距，并覆盖冷绘制与已有纹理两条执行路径。
