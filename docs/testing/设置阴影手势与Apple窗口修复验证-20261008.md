## 用户最小手测

使用最终同证书候选保留数据覆盖后，按以下顺序观察并反馈：

1. 冷启动后从设置→歌词库→Apple Music→登录第一次打开，观察有无立即闪退、首帧是否已完整铺开；返回设置，再连续复开两次，分别用左上返回、右上关闭和系统返回关闭。
2. 在官方账号输入框点击输入，观察键盘是否出现、网页是否随键盘缩小、输入和按钮是否可见可操作。账号、密码和验证码仅在官方页面输入；真实账号授权成功仍待用户测试。
3. 在有有效封面的普通／全屏歌词页，反复轻触手势条、长按、垂直滑动和取消，背景应持续保留；横向拖动、收放动画中轻触、真正中途抓取与返回应正确衔接。
4. 同一主题、同一歌曲下，区分首次进入设置／歌词页的冷路径和复开后的暖滚动，观察开关、滑条及改变卡片高度的选项。阴影应水平对称、向下柔和，浅深主题无黑边或接缝；如仍卡顿，反馈具体页面／操作／冷暖差别，再对同包测帧时间，旧整进程gfxinfo不代验新设置页。
