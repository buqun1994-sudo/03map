## 框架与修正范围

- [ControlDefinition／ControlCatalog](<../../source/amap-9.5.0.600013/content-compose/model/com/icar03/content/model/ControlDefinition.kt>) 统一稳定语义、renderer、展示面和跨度；[ContentVehicleConfig](<../../source/amap-9.5.0.600013/content-src/com/autonavi/amapauto/content/ContentVehicleConfig.java>) 消费 schema2 的受控 adapter、读写 mapping、raw↔semantic 编码、signals 和有序初始布局。未知 adapter／非法映射拒绝；未实现、禁用或静态缺失隐藏，暂时离线可见但禁用。气候当前隐藏，资格仅 ControlCard／Gesture。
- 普通分页只有车辆信息、歌词、投影，默认车辆信息。应用控制中心是覆盖层，独立于 OEM `system_control_center` 动作和当前网格数量；后者不取得 Dock 资格。
- [ContentStore](<../../source/amap-9.5.0.600013/content-src/com/autonavi/amapauto/content/ContentStore.java>) 持有业务与有序布局真值；[LayoutSession／LayoutEditor](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/LayoutEditor.kt>) 保证互斥。普通卡列表复用真实控件，编辑时只派发布局；固定添加行、当前卡蓝框、空列表和任意数量 Dock 均进入统一偏好链。
- [EditableControlLayout](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/EditableControlLayout.kt>) 与 [ControlEditDrag](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/ControlEditDrag.kt>) 共用候选／目标会话。布局资格与业务交互分开，继续保留生命周期、焦点、可见性与多指仲裁；帧和滚动互斥挂起后重新核对会话代际，避免松手后迟到帧访问空会话。
- 候选的窗口坐标采样移到自身位移图层内，与指针输入采用同一坐标空间；普通清理按实际来源 token，避免同 ID 预览项销毁时误取消来源。完整父层原生回归覆盖移入、等绘制、移出、重入、独立 UP、单次 Drag 提交及零业务／音效；根与生命周期失效仍立即取消。
- [ControlCenterOverlay](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/ControlCenterOverlay.kt>) 的添加目录使用独立全屏 lease，关闭恢复内容／地图端点。媒体卡按自身行高计算内部几何，修正全屏目录中字体／图标溢出；Dock 编辑面板按内容高度从底部布局，修正标题与顶栏重叠。
- [VehicleConfigImportSession](<../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/VehicleConfigImportSession.kt>) 持有 picker journal、URI grant、有界读取、私有 staging 和原子保存；[ContentRuntime](<../../source/amap-9.5.0.600013/content-src/com/autonavi/amapauto/content/ContentRuntime.java>) 可在 Host 未恢复时接收结果。失败保留旧配置，保存后下次冷启动激活；自检只读，同配置／环境可复用。
- 有效 Tap 统一经过一次 `ContentClickSound`；LongPress／Drag、取消、禁用、拒绝及状态回流静音。此处事件计数已验证，静音模拟器不证明实际 OEM 音效听感。
