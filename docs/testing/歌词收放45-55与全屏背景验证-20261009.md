# 歌词收放45／55与全屏背景验证（2026-10-09）

用户要求将前景动画调整为0～45%渐隐、45～55%透明排版缓冲、55～100%渐显；彻底删除临时过渡图案，全屏模糊背景在第一段建立。按当次要求只做定向验证，完成后提交源码，实车由用户下次手测。

## 实现与源码证据

- [ContentPresentation](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/ContentPresentation.kt>)使用45／55边界，排版仍在50%切换。背景共用`presentationAmbientBlend()`，即`1 - presentationCompactAlpha(p)`；0～45%平滑建立，随后保持完整，反向沿同一进度回到compact。
- [AmbientPresentationScene](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/AmbientPresentationScene.kt>)仅保存实际compact／wide端点，删除桥接位图、边缘取色和渐变延伸。wide在固定fullSize坐标绘制并按可见边界clip，compact保持原生小屏宽度；右侧下层为高德真实主题底色。
- [MediaAmbientBackground](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/MediaAmbientBackground.kt>)在退出时独立烘焙compact，不将wide捕获挤压成小屏；无封面仍准备不透明主题端点并应答进入请求。尺寸变化优先捕获presentation实际混合帧及其真实尺寸；requestId／纹理／主题／几何／session拒旧，停止释放引用，已发布或已捕获位图不主动recycle。
- 背景主体取消正向`sceneProgress`重映射；迟到worker保留当前真实帧，沿累计实际移动的4个百分点完成交接，支持反向且无第二计时器，端点显式兑现。正常按钮先等待端点就绪，45%即完整wide；手动拖动若准备迟到，优先保留实际画面，交接可能短暂跨过45%。正常两端点绘制至多2张位图，迟到／尺寸变化的短交接至多3张有界位图。
