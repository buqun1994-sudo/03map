## 1. 原崩溃与修复边界

用户在上一候选操作后报告崩溃。本机保存的[原始崩溃日志](<../../.tmp/lyrics-fullscreen-fix-20261006/crash-before.log>)在12:52、12:59、13:01三次记录了主线程 `IllegalStateException: Cannot insert LayoutNode ... because it already has a parent`，调用栈经过 Compose `LayoutNodeSubcompositionsState.subcompose()`，另有[原运行帧](<../../.tmp/lyrics-fullscreen-fix-20261006/before.png>)。这些是旧包的现场错误证据，不是新包的运行证据。

[ContentPanel](<../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/ContentPanel.kt>)旧路径把可移动歌词子树在 Pager 的 Lazy/Subcompose 父节点与宽屏根节点间转移。本轮在根 `Layout` 的固定调用位置保留一个生产 `HorizontalPager`，歌词只在其中挂载一次；收放只改变测量和放置端点，消除跨父节点插入的结构。普通歌词位于顶栏下、媒体卡上，全屏位于右侧约2/3全高。预览分支与生产分支独立，未新增 Store、播放器或地图控制器。

本机 UI 与 Host 的逐帧节点身份回归已覆盖收放跨界；新包是否在目标车机上完全消除用户这次崩溃，仍须同一最终包安装后的实际地图展开、返回及日志证据。

## 4. 定向回归与测试夹具修正

本轮保留了严格行为断言，未以空Pager存在替代歌词正文、未放宽未知位置或恢复时间合同。

- [设置回归](<../../ui-preview/content-ui/src/test/java/com/icar03/content/ui/SettingsSheetInteractionTest.kt>)覆盖API28／34、双主题及141／212／320DPI。`performClick()`实际注入触摸，Compose UI Test 1.7.6 的默认MOVE推进16ms，即使 `autoAdvance=false` 也会前进；因此重开位置必须在被拒绝触摸之后重新采样，语义事件使用 `performSemanticsAction(OnClick)`，并断言动作自身不推进时钟。重开预算被剩余退出距离约束，确保回到底部再入场不能通过。
- [Host回归](<../../ui-preview/map-host/src/test/java/com/icar03/content/host/ContentImmersiveHostTest.kt>)使用正式 Store 输入，不通过反射同时写shell／lyrics替代业务发布。[定向报告](<../../apk-work/validation.TAZ6a3/report.json>)10项API28／34测试通过。直接使用生产recomposer时，Compose 1.7.6主线程dispatcher在方法间缓存排队标志，而Robolectric 4.14.1会清平台回调队列；本机字节码确认了销毁回调丢失后无法重新post的路径。`@After`在Host／Store／Activity销毁之后推进64ms主Looper，先处理取消回调再交给测试环境重置，完整class通过。没有反射清dispatcher、替换生产recomposer或降低歌词节点断言；未采运行中的dispatcher标志，因此缓存路径的归因保留静态边界。
- [进度合同](<../../ui-preview/content-ui/src/test/java/com/icar03/content/ui/ImmersivePlaybackProgressTest.kt>)停止／恢复夹具的[定向报告](<../../apk-work/validation.IEZmkM/report.json>)实际执行API28／34两项、失败／错误／跳过0。自定义LifecycleOwner手工改变CREATED／STARTED后需按既有可见性测试合同显式投递Snapshot通知；修正前可信轨迹10004ms、标签仍0:05，修正后标签0:10。STOP时独立重组探针仍可更新，避免用暂停的Recomposer假代采样停止。生产采样保留 `rememberLyricVisibility()` 与 `repeatOnLifecycle(STARTED)`，没有新增测试时钟接口或第二业务时间线。
