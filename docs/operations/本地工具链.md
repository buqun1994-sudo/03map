# 本地工具链

## 1. 配置入口

本机路径和设备 serial 只写入被 Git 忽略的 `.codex/local-context.properties`。模板见 [.codex/local-context.properties.example](../../.codex/local-context.properties.example)。

建议配置这些变量：

- `JDK17_HOME`
- `ANDROID_SDK_ROOT`
- `PRIMARY_ADB`
- `APKTOOL_JAR`
- `BAKSMALI_JAR`（可选；需完整依赖）
- `SMALI_JAR`（可选；必须是独立汇编器，不与 `BAKSMALI_JAR` 共用）
- `AAPT2`
- `ZIPALIGN`
- `APKSIGNER`
- `VEHICLE_ADB_SERIAL`
- `TEST_PHONE_ADB_SERIAL`（可选）

当前已确认的本机工具版本：`apktool 3.0.3`、JDK 17、Android SDK Platform Tools、Build Tools、Smali 3.0.9。实际路径以本机配置为准。

## 2. 工具职责

| 工具 | 作用 |
|---|---|
| `adb` | 设备发现、安装、启动、截图、窗口查询和日志；历史广播仅按专项授权使用 |
| `apktool` | APK 解包、资源 / Manifest / 常规 Smali 修改、重打包 |
| `baksmali` | DEX 反汇编 |
| `smali` | Smali 汇编为 DEX |
| `aapt` / `aapt2` | 包名、版本、入口、权限、资源检查 |
| `zipalign` | APK 对齐 |
| `apksigner` | APK 签名、证书摘要和签名验证 |

## 3. 常用环境变量

以下命令假定当前终端已经按本机配置设置变量：

```sh
JAVA="$JDK17_HOME/bin/java"
export JAVA_HOME="$JDK17_HOME"
ADB="$PRIMARY_ADB"
APKTOOL="$APKTOOL_JAR"
```

不要把本机路径写回仓库文档，也不要把密钥路径、口令或证书私钥放入环境变量示例。

## 4. 版本和完整性检查

```sh
"$JAVA" -version
"$JAVA" -jar "$APKTOOL" --version
"$ADB" version
"$AAPT2" version
"$APKSIGNER" --version
```

如果系统 `/usr/bin/java` 只是 macOS shim，必须使用 `JDK17_HOME` 指向的 JDK 绝对路径，并设置 `JAVA_HOME`，这样 `apksigner` 等 SDK 包装器也会使用同一套 JDK。

## 5. ADB 连接检查

```sh
"$ADB" devices -l
"$ADB" -s "$VEHICLE_ADB_SERIAL" shell getprop ro.product.model
"$ADB" -s "$VEHICLE_ADB_SERIAL" shell wm size
```

每次操作都显式带 `-s`。如果设备不在 `device` 状态，先停止安装和修改，记录断开原因，再恢复连接。

## 6. 设备证据

```sh
"$ADB" -s "$VEHICLE_ADB_SERIAL" exec-out screencap -p > "$TMP_SCREENSHOT"
"$ADB" -s "$VEHICLE_ADB_SERIAL" shell dumpsys window windows
"$ADB" -s "$VEHICLE_ADB_SERIAL" logcat -d -v threadtime -t 300
```

截图和日志只放临时目录，不复制到 Git。
