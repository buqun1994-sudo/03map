# 本地工具链

## 1. 配置入口

本机路径和上次成功的设备 serial 只写入被 Git 忽略的 `.codex/local-context.properties`；旧 serial 不能作为当前在线证据。模板见 [.codex/local-context.properties.example](../../.codex/local-context.properties.example)。

建议配置这些变量：

- `JDK17_HOME`
- `ANDROID_SDK_ROOT`
- `PRIMARY_ADB`
- `APKTOOL_JAR`
- `BAKSMALI_JAR`（可选；需完整依赖）
- `SMALI_JAR`（可选；必须是独立汇编器，不与 `BAKSMALI_JAR` 共用）
- `AAPT2`
- `ZIPALIGN`
- `APKSIGNER`
- `AMAP_SIGNING_PK8`、`AMAP_SIGNING_CERT`（仓库外的长期签名私钥与证书路径；当前构建脚本在缺失或身份不符时失败）
- `VEHICLE_ADB_SERIAL`
- `TEST_PHONE_ADB_SERIAL`（可选）

当前已确认的本机工具版本：`apktool 3.0.3`、JDK 17、Android SDK Platform Tools、Build Tools、Smali 3.0.9。静音原生补丁使用SDK内`NDK 27.0.12077973`的clang integrated assembler、LLD、objcopy、nm、readelf；其工具SHA和NDK版本文件纳入正式构建前后指纹。ARM64行为回归使用本机忽略目录的`Unicorn 2.1.4`，不作为APK依赖；命令与证据边界见[静音修复验证](<../testing/地图静音持久化修复验证记录-20261004.md>)。实际路径以本机配置为准。

## 2. 工具职责

| 工具 | 作用 |
|---|---|
| `adb` | 设备发现、安装、启动、截图、窗口查询和日志；广播按任务目标核对接口及参数 |
| `apktool` | APK 解包、资源 / Manifest / 常规 Smali 修改、重打包 |
| `baksmali` | DEX 反汇编 |
| `smali` | Smali 汇编为 DEX |
| `aapt` / `aapt2` | 包名、版本、入口、权限、资源检查 |
| `zipalign` | APK 对齐 |
| `apksigner` | APK 签名、证书摘要和签名验证 |

## 3. 常用环境变量

以下命令假定当前终端已经按本机配置设置变量：

```sh
JAVA="$JDK17_HOME/bin/java"
export JAVA_HOME="$JDK17_HOME"
ADB="$PRIMARY_ADB"
APKTOOL="$APKTOOL_JAR"
```

可复制的命令使用变量名；真实非公开私钥、口令和有效凭据不进入示例。本机路径的实际隐私判断见 [安全与密钥边界](../security/安全与密钥边界.md)，不单凭绝对路径格式禁止记录。

## 4. 版本和完整性检查

```sh
"$JAVA" -version
"$JAVA" -jar "$APKTOOL" --version
"$ADB" version
"$AAPT2" version
"$APKSIGNER" --version
```

如果系统 `/usr/bin/java` 只是 macOS shim，必须使用 `JDK17_HOME` 指向的 JDK 绝对路径，并设置 `JAVA_HOME`，这样 `apksigner` 等 SDK 包装器也会使用同一套 JDK。

## 5. ADB 连接检查

电脑端车机发现先执行发现脚本，避免使用过期连接信息。它复用当前 ADB Server 中身份匹配 `S56_HQX / SDK 28` 的在线车机；未命中时才由 Cloud 共享脚本对有界物理私有网段探测 TCP `5555` 并再次核验身份。地图仓库只转发本机配置和参数，不复制扫描算法；如 Cloud 不在同级目录，可设置 `THREE_APP_CLOUD_ROOT`。入口失败后按实际输出诊断连接，设备身份未重新核验前不改用旧 serial 继续安装。

```sh
VEHICLE_ADB_SERIAL="$(node scripts/find-vehicle-adb.mjs --serial-only)" || exit 1
"$ADB" devices -l
"$ADB" -s "$VEHICLE_ADB_SERIAL" shell getprop ro.product.model
"$ADB" -s "$VEHICLE_ADB_SERIAL" shell wm size
```

每次设备任务重新获取当前 serial，后续操作都显式带 `-s`。如果设备不在 `device` 状态，先停止安装和修改，记录断开原因，再恢复连接。该入口只负责电脑端发现，不改变 APK 身份或用户任务范围。

## 6. 设备证据

```sh
"$ADB" -s "$VEHICLE_ADB_SERIAL" exec-out screencap -p > "$TMP_SCREENSHOT"
"$ADB" -s "$VEHICLE_ADB_SERIAL" shell dumpsys window windows
"$ADB" -s "$VEHICLE_ADB_SERIAL" logcat -d -v threadtime -t 300
```

原始截图和日志先放临时目录；有入库需要时按实际内容脱敏，不一律禁止截图或日志摘要进入 Git。
