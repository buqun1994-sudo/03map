# 安全与密钥边界

本文件只记录会给用户带来具体损失的风险。源码组织、构建步骤和功能验证分别见 [APK 工作流](../operations/APK工作流.md)、[内容区主链](../architecture/内容区主链.md) 和 [验证矩阵](../testing/验证矩阵.md)。

## 凭据与隐私

- 非公开私钥、keystore 密码、有效 token、账号 cookie 等进入 Git 历史或发送给他人，会造成签名冒用、账号访问或费用损失；这些值留在忽略的本机配置或仓库外，不提交、不对外发送。
- 日志、截图、录屏和 fixture 含账号、住址、精确位置、行程、联系人或可关联用户的设备标识时，原始证据留本机；提交或分享必要片段前脱敏。确需发送原始敏感内容时，确认接收方和范围。
- 文件类型、公开证书、公开测试密钥、普通本机路径或局域网地址本身不自动构成泄密。按实际内容判断是否暴露个人信息、有效凭据或设备访问能力；脱敏截图和日志摘要可以作为版本化证据。

## 数据丢失与设备中断

- 卸载、清数据、不兼容降级或身份迁移可能丢失登录、离线地图、搜索记录和用户配置。安装失败不能自动升级为这些操作；先说明数据影响和恢复办法，超出用户已明确目标时再确认。
- 重启车机、停用服务、修改系统配置或权限，只有实际中断导航、音频、设备操作或产生持久影响时才需要说明后果和恢复办法，不按操作名称一律暂停。
- 普通保留数据覆盖安装、启动、只读取证、本机构建和测试不另设授权门槛。Release、instrumentation、广播、root、CAN、无障碍是包类型或技术方式，风险取决于实际动作和后果。

## 真实车辆动作

- 设备写入前核对当前目标车辆、控制对象和目标值，避免操作错车、错座椅或误锁车。用户明确要求的车控验证覆盖对应操作及恢复，不逐条重复询问。
- 未包含在用户目标中的实体车辆动作，或可能影响乘员、驾驶安全、防盗状态、充电及硬件且后果或恢复方式尚不明确的实验，先说明具体风险并确认范围。状态异常或发生意外动作时停止继续试写。
- 正式车控保留真实状态回读、拒绝、断连和超时反馈，避免把命令发送当作成功。不另加本地 P 档或零速产品限制，驾驶条件由原车系统处理，见 [产品基线](../product/产品需求基线.md)。

## 当前签名与确认原则

当前候选包使用公开的 AOSP testkey。持有该公开私钥的人可以生成同签名包，因此它只用于现有安装兼容，不能证明包的可信来源。证书摘要和签名校验仍用于核对兼容身份，不等于私钥保密。

更换签名可能使原安装无法保留数据覆盖；迁移时说明安装兼容、数据保留和回退方案。用户已经明确要求且了解这些影响时直接执行。

只在具体个人风险超出用户明确目标，或缺少决定损失范围的必要信息时询问，并说明实际后果。已有指令覆盖的目标、操作和影响无需再次确认；抽象的“可能不安全”或其它项目的规则不增加本仓库限制。
