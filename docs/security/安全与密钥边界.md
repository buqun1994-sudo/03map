# 安全与密钥边界

## 1. 禁止进入 Git

1. 原始或重打包后的 APK、AAB、DEX、临时解包目录和构建产物。当前版本唯一例外是用户明确要求纳入正式代码的 `source/amap-9.5.0.600013/` 解包源码快照；其中不得加入原始 APK、DEX、签名材料或 `build/` 产物。
2. keystore、私钥、证书口令、token、账号 cookie 和任何商业服务凭证。
3. 车机 / 手机 serial、IP 地址、完整 `logcat`、截图、录屏、定位轨迹和个人信息。
4. 包含真实用户数据、地图搜索记录或第三方服务响应的 fixture。
5. 本机绝对路径；路径只进入被忽略的 `.codex/local-context.properties`。

## 2. APK 修改边界

1. 只在用户拥有合法使用和测试权的 APK 上操作。
2. 包名和签名是 Android 应用身份的一部分；改变它们必须有明确的测试目的、证书记录和安装验证。
3. 静态修改用于验证窗口承载和界面复用，不承诺绕过服务端授权、账号限制、商业许可或加密完整性保护。
4. 第三方地图数据、定位、路线和车道级提示受地图服务、账号、地区、网络和固件能力约束，不能由本仓库文档替代授权。

## 3. 设备和权限边界

1. ADB 只用于开发、安装、日志和实机取证，不进入正式运行依赖。
2. 不要求 root，不连接 CAN，不写车辆状态，不执行车辆安全相关操作。
3. 悬浮窗只承载地图显示和用户主动触发的导航界面，不扩大为后台截图或持续轮询。
4. 读取日志遵循最小范围；发现可能含个人信息时立即停止扩散并只保留必要错误片段。

## 4. 人工门禁

以下动作必须获得当次明确指令：修改正式签名或包名、卸载 / 清数据 / 降级、重启车机、安装 Release、运行 instrumentation、暂停无障碍、导出包含个人信息的日志、发布或上传 APK。
## 5. 正式源码快照边界

1. `source/amap-9.5.0.600013/` 只表达本版本 APKTool 3.0.3 解包后的可追踪源码和运行资源，不代表已获得第三方代码再发布许可。
2. 任何改动仍从该快照复制到被忽略的 `apk-work/` 工作副本，构建产物、安装包和运行证据不回写到 source。
3. 切换地图版本时建立独立仓库和独立版本目录；不覆盖当前快照，不混用资源 ID、Smali 类名或签名身份。
