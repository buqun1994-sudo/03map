# `480×480` 悬浮地图支线

## 1. 封存目的

当前产品主线已经切换为全屏动态分屏；历史 `480×480` 悬浮地图不删除、不回写到全屏分屏主线，作为后续可继续研究的独立支线保留。

## 2. 本机封存入口

1. 封存代码副本位于被 Git 忽略的 `apk-work/9.5.0.600013/archive-480x480-20260924/`。
2. 该副本来自上一轮 `stage1-final-roundtrip-73c906` 的回解结果，保留原有悬浮窗口、启动、Surface 接管和拖拽相关修改。
3. 当前全屏分屏施工副本是同目录下的 `decode/`，它从正式 `source/amap-9.5.0.600013/` 基线建立；两者不能交叉覆盖。

## 3. 后续恢复方式

1. 继续研究悬浮版时，从封存副本复制新的临时施工副本，不直接修改封存副本。
2. 继续研究分屏版时，从正式源码快照或当前分屏施工副本继续，不把悬浮支线的窗口主链带回分屏主线。
3. 封存副本不是新的正式源码真值；包身份、输入 APK 和正式代码地图仍以 `docs/archive/amap-9.5.0.600013.md`、`docs/code-map/基线清单.md` 和 `source/amap-9.5.0.600013/` 为准。
