## 2026-09-28 实机验证反馈

本轮新施工仅完成本机验证；以下五条仍是上一候选的实机反馈，不能当作新包的实机结论。

以下结论来自用户在车机上的实际测试，证据等级为“实机确认”；本轮只记录问题，不将未完成的适配器静态接入描述为功能闭环。

1. **视觉质量：** UI 比上一轮改善，但整体仍然丑，需要继续按车机级标准精修视觉层级、尺寸、间距、控件形态和整体和谐度。
2. **车控状态不可用：** 温度、电量信息、充电信息、座椅通风、座椅加热和座椅按摩均不可用；后续必须核对权限、服务可达性、读取 / 订阅、命令、成功回流、失败回流和可逆恢复，不能用静态预览冒充真实状态。
3. **页面与控制区可视宽度错误：** 页面项实际宽度没有等于内容板块可视宽度，当前页会露出第二页内容；控制区同样会露出下一张卡。后续必须由独立可视 viewport 和裁剪边界统一约束，禁止相邻项泄漏。
4. **滑动动画不达标：** 页面滑动和控制区滑动均显得僵硬，不满足车机使用场景下的丝滑过渡要求；后续需要统一拖拽进度、吸附阈值、速度处理和非线性缓动。
5. **媒体氛围背景范围错误：** 当前歌词背景只在歌词页出现，且只有切换到歌词页后才出现。目标应改为：只要媒体正在播放，就根据专辑封面采样主色并以模糊 / 渐变氛围背景覆盖整个内容板块；背景位于顶栏、页面、控制区和 Dock 的下层，与当前页面无关；未播放或无封面时回退主题背景。

**当前 SVG 签名包已通过本机自动验证，车机离线阻断本轮同包安装与启动。** 现场恢复后先运行唯一发现入口，再按验证矩阵保留数据覆盖安装当前哈希，绝不借用旧包证据；具体结果见 [专项验证记录](testing/SVG内容区复刻验证记录-20260928.md)。
1. 当前 SVG 包尚未安装；进程、双 Surface、分屏首帧、收放／中途接管和三视角等交互均待同包现场验收。
2. 在真实 `px / density` 下复核两色两页两卡、顶栏长文案、四项快捷和六槽 Dock、页面／控制卡稳定态邻项 `0px`、弹层与触摸热区；本机模拟通过不取代驾驶视距下的尺寸、亮度和参考风格判断，发现差异后只回调内容布局令牌，不变更地图几何。
3. 用真实媒体播放／暂停／无封面、切换页面、地图收放和 Activity 重建，确认全局封面层、已纳入七份 Lottie 的停播／单次过渡与系统资源颜色在目标 Android 9 上实际成立；通风／加热／按摩暂用同套静态 Vector，不宣称动态图标已通过。
