# 设置页 UI 规则

用户提供的两张 Figma 导出图用于确认布局、控件形态和交互关系；示意字号、单位和颜色值不作为精确测量基线。本轮只调整03地图内容区设置，不改DeepSeek Harness界面或03lyrics源码。

## 层次与主题

1. 设置页依次按规则、原子控件、页面组合施工。主题唯一输入仍为高德已经解析出的 `dark`，不增加设置主题开关或用系统 `uiMode` 覆盖内容主题。
2. 设置专用表面、文字、分隔线、滑条、分段选中、开关与圆角集中于 [SettingsDesign](../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/SettingsDesign.kt)。浅色为灰色页面／白卡片／更浅选中面；深色为炭黑页面／深灰卡片／更亮选中面。设置视觉角色不修改快捷车控、媒体卡及Dock的既有颜色角色。
3. 页面标题为常规字重，导航项目和“标题·当前值”为粗体。数据标题跟随实时草稿或已保存值更新，不能留示意常量。窄幅文字自然换行，不能切掉HEX、单位或完整平台名。
4. 常规水平内边距24dp、窄幅16dp；设置段间距28dp。卡片和预览角10dp，数值滑条与分段选择使用胶囊，色相条8dp角、色块4dp角。交互热区至少48dp；宽度不足的色阶或选项使用标准横向滚动，保持完整可达。

## 原子控件

[SettingsControls](../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/SettingsControls.kt)封装既有 Material3 1.3.1 的 `ListItem`、`IconButton`、`Surface`、`Slider`、`Switch` 和 `SegmentedButton`。平台选项使用标准Material选择控件。仅统一皮肤、参数、草稿和事件；触摸识别、滑动、焦点、选中与无障碍由成熟组件承担，不另写Canvas或触摸控件。

- 数值滑条实时预览，结束一次提交；取消恢复原草稿且不写偏好。退出或禁用后不提交。
- 分段选择同组最多一项；平台倾向也是单选，不能将已选项再次点为空。
- 颜色条以标准Slider拖动色相；十色色阶用AndroidX `ColorUtils` 的HSL转换，从同一色相按固定明度生成，重复点击不会逐次变暗。两套自定义颜色分别保留。
- 有效按钮和色块点击统一经过 `ContentClickSound`；数值拖动、色相拖动、取消、禁用与状态回流不播放点击声。

## 页面组合与导航

1. 面板始终留在左侧初始1/3内容区域，宽度固定消费分屏展开端点，不随歌词全屏或当前宿主实际宽度扩大；保留与Dock左右边界、媒体卡底边的锚定关系。设置首页使用图标＋完整名称＋右箭头的分组导航行，不保留左菜单／右详情布局。
2. 首组为状态栏与底栏，第二组为歌词与背景，后续保留媒体和交互等现有入口；入口清单可扩展。
3. 首页返回关闭设置，子页返回首页。硬件返回遵循同一层级，Apple登录层优先关闭自身。关闭动画结束前继续保留模态门禁。
4. 歌词页固定标题栏和三句示例歌词预览；“歌曲平台倾向”及其以下控件独立纵向滚动。预览复用现有原生歌词绘制路径和 [LyricSettingsStyle](../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/LyricSettingsStyle.kt)；不依赖当前播放歌曲。
5. 歌词页顺序为：平台倾向、普通字号、句间距、对齐、普通色、当前句放大、当前句字号、当前句颜色、对唱布局、沉浸式全屏字号、沉浸式全屏句间距。调整全屏参数时固定预览切到缩略全屏呈现。
6. “当前句放大”关闭只取消字号放大并禁用其字号滑条，保留字号偏好、当前句清晰显示及独立配色；对唱布局只消费真实声部，不伪造身份。
7. “跟随主题”采用高德日夜文字色，“系统主题色”采用03lyrics已验证的公开车机主题键强调色规则，“自定义”采用该组独立RGB。读取失败或未知主题键沿现有默认强调色回退，不用Android12动态色替代Android9车机路径。
8. 平台倾向复用既有 `ContentLyricsPreferences` 和实际Provider调度，保留AUTO与八个平台以及失败回退。Apple通过既有 `AppleMusicConnection` 在原生WebView呈现官方登录，不要求用户向应用提交账号、密码或token；关闭停止认证检查，凭据沿既有加密私有存储。

偏好默认值、范围和迁移由 [设置项清单](设置项清单.md)及实际Store owner维护；双主题原生绘制与本机／实车证据分别记录在本轮验证文档，不以PNG概念或本机帧替代车机验收。
