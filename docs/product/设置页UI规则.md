# 设置页 UI 规则

本轮设计来自已连接的 Figma `Untitled` 当前选区：设置首页 `1:7`、状态栏设置 `1:32`、歌词设置 `1:104`。布局、字体、颜色、间距与截图已通过本机 Desktop Bridge 读取；用户确认间距使用 dp、字号使用 sp。此前示意图及未验收阶段截图不再作为本轮视觉基准。设置依次按设计令牌、原子控件、页面组合实现。

## 间距与尺寸

所有页面布局间距只使用 12／24／48dp，集中于 [SettingsDesign](../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/SettingsDesign.kt)。24dp 边距在窄幅也保持。

| 角色 | 规则 |
|---|---|
| 顶部返回 | 按钮左边距24，透明背景，至少48高的独立热区 |
| 页面标题 | 居中，文字框距离顶部及下方分隔线均24 |
| 第一个板块 | 从顶部分隔线下方24开始 |
| 板块之间 | 前一卡片底部至下一板块标题48 |
| 板块标题 | 页面左边距48；标题至卡片24 |
| 卡片背景 | 页面左右各24；内容左右各24 |
| 卡片项目 | 项目文字框至卡片顶部、分隔线和底部均24；长名称自然换行 |
| 有图标的导航行 | 图标距卡左24、图标24宽、名称距图标24；分隔线从名称左边开始，距卡右24 |
| 无图标的行 | 名称与开关距卡两边各24；分隔线左右各24 |
| 数值调节 | 常规24字号；分屏与全屏同组，136宽标签列＋12间隔，即滑条起点偏移148；分屏／全屏滑条同宽；内容宽不足360时按12间距上下排布 |
| 数值条 | 40高胶囊，进度填充蓝色 `#0086FD`；触摸、取消、焦点与无障碍沿成熟Material3／Foundation路径 |
| 单选分段条 | 底框为56高、8dp圆角矩形；选中面52高、6dp圆角矩形、四周2dp内缩；两种主题统一数值滑条蓝色 `#0086FD`＋白色文字，保留完整文字和等宽选项 |
| 色相条／色阶 | 同为60高、总宽相等；色阶八个无缝等分且完整可见，无内部横向滚动 |
| 色相选择框 | 60×60、4圆角、白色4描边、内部显示当前饱和色 |

开关视觉统一为60×30，滑块30×25、边缘内缩2.5dp，开启态两种主题均为绿色 `#33C458` 配白色滑块；关闭态保留各主题灰色。整行右侧对齐不变，单行文字框30高，使单行卡片总高为78；长偏好名称按同一24sp字号自然换行，行和卡片随正文增高，不裁切名称。整行使用标准 `toggleable` 和系统最小触摸扩展，独立开关保留48热区。八段色阶在窄幅按总宽等分，保留60高；不把旧的固定48宽色块强行塞入或滚动。

## 字体、颜色与阴影

Figma 使用 `Microsoft YaHei UI`；Android 设置复用项目已有系统 sans-serif 字体来源，按图中的字号、字重和行高层级排布。字体字形与车机实际字体分别核对。文本禁用Android旧font padding，行框居中且不trim，以声明的30／33／36sp行高布局，不用额外行高撑大卡片。

| 文字角色 | 字号／行高 | 字重 |
|---|---|---|
| 页面标题 | 28sp／36sp | 常规400 |
| 板块标题 | 26sp／33sp | 粗体700 |
| 项目、卡片内标题、数值 | 24sp／30sp | 常规400 |
| 分段选项 | 22sp／28sp | 常规400 |
| 歌词库平台选项 | 24sp／30sp | 常规400 |
| 辅助状态 | 18sp／24sp | 常规400 |

浅色页面 `#F4F4F4`、卡片白色、文字 `#27303B`、轨道 `#E9E9E9`、分隔线 `#E7E7E7`。深色沿已有高德日夜状态适配为 `#0F0F0F` 页面／`#1A1A1A` 卡片／`#303030` 轨道；设置单选分段及平台选项的选中矩形统一由 `SettingsDesign.selected` 复用 `sliderFill` 蓝色；`pressed` 仅拥有主题灰色按压反馈。车控、媒体及Dock仍消费各自既有颜色角色。

页面12圆角、卡片8圆角、色相及色阶整体8圆角。Figma卡片阴影参考向下2、模糊4、黑色25%；Android沿既有共享`downwardSoftShadow`的显式水平0／向下3dp、模糊5dp与主题alpha，和Dock、媒体、快捷功能共用同一绘制owner，并通过原生帧检查水平对称／下重。冷路径预渲染阴影纹理，稳定绘制只贴缓存，不每帧执行模糊；导航行、开关、数值条、色相和色阶不重复叠加容器阴影。系统elevation光源会导致左重，不替代已验收的向下阴影。

八段明暗参考为Figma黄系50／200／400／600／700／800／900／950：`#FEFCE8 / #FEF08A / #FACC15 / #CA8A04 / #A16207 / #854D0E / #713F12 / #422006`。其它色相沿同一参考的饱和度、明度与色相偏移生成。色相渐变使用读取到的八个不等距停止点；滑条位置与真实HSL色相分段互映。重复选择固定色阶不会逐次变暗；旧任意RGB保持原值，不吸附到新色板。

设置页的界面透明度只作用于页面、卡片、轨道、选中面、按钮等浮层背景及其阴影；标题、项目文字、图标、开关滑块和其它内容不随该值整体淡出。页面位置转场、按压反馈和禁用态仍使用各自alpha；独立网页登录Window保持不透明。

[SettingsControls](../../source/amap-9.5.0.600013/content-compose/ui/com/icar03/content/ui/SettingsControls.kt)统一 `SettingsSection`、`SettingsFieldBlock`、`SettingsDivider`、`SettingsNavigationItem`、`SettingsSwitchRow`、`SettingsSliderRow`、`SettingsSegmented`、`SettingsColorPicker`。原子层只接值与回调；成熟Material3／Foundation控件拥有输入、焦点与无障碍，页面不自造手势。

1. 设置面板固定在原左侧1/3区域，首页按“布局／音乐／其它”组织已有六个入口；首页返回关闭，子页返回首页。上下移收起按钮仅在“歌词设置”子页显示，只依据设置当前栏目，与底层页面无关；收起期间露出的内容点击恢复原栏目，原操作不穿透，全部设置栏目仍继续正常歌词跟随。
2. 所有子页固定标题栏、下方独立滚动。歌词设置移除三句预览。
3. 状态栏按时间、温度、电池、沉浸式全屏组织。续航、插枪、预约、剩余时长与功率各自可保存且沿真实消费者生效；充电完成文案归插枪显示控制。
4. “状态栏保持分屏”开启时，全屏歌词顶栏保留左侧初始宽度；关闭时使用全屏宽度，与顶栏是否显示分开保存。
5. 歌词页依次为歌词库、歌词、当前句歌词、对唱布局、歌词翻译。歌词板块内字号和句间距各有分屏／全屏两行，随后是位置与颜色。当前句板块有放大、两种字号与独立配色。
6. 全屏当前句字号独立保存；关闭放大折叠隐藏当前句字号调节区，保留当前句清晰强调和独立配色。翻译开关只控制已有译文的呈现，不删除正文或缓存。
7. 平台使用实际AUTO＋八个平台的图标和全名，图标32dp、文字24sp，次于26sp粗体板块标题和28sp页面标题；按实际文字样式测量最长名称，以“32dp图标＋12dp间隔＋最长文字”确定公共组宽度并在每个按钮内居中，其它项共用该组的图标左锚。圆角矩形蓝色选中、白色文字、单选、不点空；指定平台先查自身目录／正文／增强，缺真实逐字或外文翻译不足才并行补强，自动模式立即提交全部可用平台；无固定平台等待窗口。两列不能容纳公共组与两侧12dp留白时纵向排布，不裁切名称。
8. 数值／色相调节实时显示草稿，结束一次保存；取消、退出、禁用和窗口中断不写入。色块及按钮沿 `ContentClickSound` 只播放一次，拖动静音。

## Apple 登录窗口

用户明确网页可单独打开且覆盖应用全屏。登录入口从歌词库卡片打开应用内独立大窗口，不受设置页1/3宽度限制；顶部返回、关闭和系统返回均结束网页登录并回到原设置页。背景点击不关闭，窗口期间其它偏好与内容按钮沿现有门禁拒绝。ComponentDialog必须使用真实宿主Activity及其WindowManager，保持默认应用token注入；Activity由ContentRuntime既有owner经ContentComposeHost与LocalContentWindowActivity传入，不从DecorContext或视图挂载时机推断；不能把View的windowToken或applicationWindowToken赋给TYPE_APPLICATION窗口。物理配置Context只构造AbstractComposeView根及WebView内容。show及网页创建前设置MATCH_PARENT、CENTER零偏移、系统栏和ADJUST_RESIZE，并在内容建立前提供物理密度和屏幕配置；不依赖后置SideEffect修正首帧，也不使用Compose Dialog按宿主dp配置重测。网页保持不透明，不继承交互UI的uiOpacity。首个predraw与复开覆盖污染宿主资源夹具，并独立检查真实Activity／WindowManager归属和框架注入的Activity应用token（区别于ViewRoot窗口binder）；Robolectric不校验真实WMS AppWindowToken，冷开、复开、账号输入及键盘仍以同包车机手测为准。

流程继续复用[LyricsSettingsBinding](../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/LyricsSettingsBinding.kt)唯一网页、attempt及生命周期，并沿[AppleMusicConnection](../../source/amap-9.5.0.600013/content-compose/runtime/com/icar03/content/runtime/lyrics/AppleMusicConnection.kt)唯一私有加密保存。用户主动连接后默认直开官方`https://music.apple.com/login`，账号、密码及验证码在Apple页面输入；有效官方`media-user-token`／`itua` Cookie由Connection接收，公开developer bearer不能确认账号连接。生产不使用固定脚本替换或基于版本号的拒绝门禁；当前车机可行性由真实页面、可交互表单及账号验证决定，见[本轮验证](../testing/五项反馈修复验证记录-20261009.md)。页面就绪仅检查可见交互，不读取输入内容；Logo或空iframe不结束有限加载期限。关闭、宿主停止和组合卸载取消Cookie检查及当前attempt并销毁网页；旧attempt／页面回调拒收。真实账号、验证码、订阅及地区需官方流程在线完成。

偏好范围、默认值与schema迁移由 [设置项清单](设置项清单.md) 及现有Store拥有。前轮Figma布局证据见 [Figma重构验证记录](../testing/设置页Figma重构验证记录-20261007.md)，本轮单选、性能与网页边界见 [修复验证记录](../testing/设置性能与媒体读取修复验证记录-20261007.md)。
