# 产品需求基线

> **职责：** 只定义用户可见的当前目标、行为和验收语义。系统边界见 [项目长期总纲](../architecture/项目长期总纲.md)，架构 owner 见 [内容区主链](../architecture/内容区主链.md)，偏好默认值见 [设置项清单](设置项清单.md)，验证证据见 [验证矩阵](../testing/验证矩阵.md)。

## 用户与目标

用户在 iCAR 03 车机壁纸状态下使用地图导航：左侧提供可扩展内容区，右侧保留高德真实地图、导航、定位和地图交互能力。当前目标是启动即进入全屏动态分屏；历史 `480×480` 悬浮地图已封存。

## 地图与手势

1. 正式输入为高德 `9.5.0.600013`、125% UI、默认全屏 APK。
2. 默认内容区约占屏幕宽度 `1/3`，地图区约占 `2/3`；地图面板保持自身宽度，收放只改变横向位置。
3. 启动首帧直接呈现展开态，不以透明页面、隐藏预览或延迟搬运掩盖过程。
4. `map_surface` 与 `ui_surface` 同步随地图面板几何变化；不以 UI 密度修改替代地图层问题。
5. 手势条只响应横向拖动；展开时位于分界处，收起时留在屏幕最右侧。松手后吸附到展开或收起稳定态，中途接管从当前位置继续。
6. 单击只显示一次轻量提示，不改变地图状态，不触发系统返回或主页动作。
7. 2D 车首、2D 北上、3D 车首均保持正确视觉焦点；不以未经验证的固定 native 偏移解决问题。

## 内容区

1. 主题只跟随高德自身解析出的浅 / 深色状态；不读取系统 `uiMode`，不维护第二套主题开关。背景和控件使用同一组高德主题令牌。
2. 首轮可见页面为 `shortcuts → lyrics`，单页横向滑动并吸附，默认主页为 `lyrics`；歌词无数据时显示“暂无歌词”及可执行的媒体来源提示，不展示施工文案；`vehicle_info`、`projection` 首轮不展示。快捷页四项车控在窄栏内不得横向裁字，更多内容可以明确提示后纵向滚动；稳定态相邻页／卡不能外露。
3. 控制区只有媒体和空调模块，默认 `media → climate`；空调和设置尚未接通时明确显示“暂不可用”，不可假亮或执行车控命令。
4. Dock 左侧固定车锁；右侧五个入口默认是快捷功能、座椅通风、座椅加热、座椅按摩和设置。
5. 歌词页 / 投屏页可进入页面沉浸式状态；快捷功能页不支持。地图重新展开时退出沉浸式状态。
6. 顶栏默认展示时间、星期、车内温度、电量和充电状态。未完成正式应用层数据闭环的项目只能显示不可用 / 预览状态，不得伪造真实值。
7. 只要媒体处于播放状态，内容区就启用媒体氛围背景：根据当前专辑封面采样主色，生成模糊 / 渐变背景并覆盖整个内容板块，位于顶栏、页面、控制区和 Dock 的下层，不依赖当前页面或是否已切换到歌词页；媒体停止播放或没有可用封面时回退到当前主题背景。
8. 页面和控制区翻页项的外层宽度等于各自内容面板的**实际可视宽度**，组件两侧的边距只放在翻页项内部。每次翻页后布局一致，稳定态右侧不截断当前项，也不露出相邻项；面板收放或宽度变化后仍按实际可视宽度对齐。
9. 车控与媒体按钮按下后立即给出触控／动画反馈，不等待车辆或媒体服务返回才开始反馈；真实成功状态仍以状态回流确认，等待、失败和超时必须明确区分，不能用即时动画冒充操作成功。

## 车机能力

1. 车控是正式产品能力范围，不是仅供研究的附属功能；车锁、座椅、空调、充电和其它已验证车机能力按统一入口逐项接入。
2. 车控入口只通过统一状态、命令端口和车辆适配器工作；页面不直接依赖厂商属性编号、Binder 事务或设备权限。
3. 每项车控能力必须完成读取 / 订阅、命令执行、成功状态回流、失败状态回流和可逆恢复验证；未完成闭环的入口显示不可用或施工预览。

## 验收语义

1. 冷启动首帧直接进入分屏展开态，比例符合默认值。
2. 地图收起、恢复、中途接管及再次启动后，地图、导航、定位和内容状态不丢失。
3. 三种地图视角无由分屏裁剪导致的相机偏移。
4. 页面、控制区、Dock 和主题变化服从统一状态，不引入重复数据源。
5. 具体验证动作和证据要求只维护在 [验证矩阵](../testing/验证矩阵.md)。
