# 简易版发布范围

适用分支：`release/lean-edition`。此分支从当前完整工作树快照派生；原完整实现仍保存在本机恢复快照`stash@{0}`，未在此分支覆盖。

## 产品入口

- 车机包名、签名身份和高德版本保持原基线；Android 应用显示名称为“03地图”。
- 启动加载内置/已保存车型映射，不在启动时对车控或系统端口执行能力自检、缓存探测或自检提示。
- 内容区唯一正式页面为歌词页；旧车辆信息、投影和分页偏好均归一到歌词页。歌词全屏按钮、地图中间手势条拖拽和分屏几何链继续保留。
- 多指手势、应用内快捷功能页、应用内控制编辑覆盖层、媒体控制长按编辑和 Dock 长按编辑均不可从产品入口触发；被移除编辑用途的媒体/Dock长按静默取消，不冒充短点击。
- 红绿灯提醒不再订阅或呈现在顶栏；其设置项已移除。

## 固定 Dock

顺序固定为：车锁、自动雨刮器、车窗透气开关、手套箱、系统控制中心、设置。Dock 不读取旧用户布局、数量或名称偏好。窗透气、手套箱和系统控制中心沿已提取的原厂 Lottie/Vector 动态资源呈现；OEM alpha 视口校准后可视高度统一为32px，Lottie完成帧保持相同尺度。手套箱接受一次开启请求后播放一次动作，不因门体无读回转为常亮或选中。

手套箱是单次开启动作，沿已研究的 `0x416/1046, area 0, value 2` 映射发送；不提供关闭动作或门体开关状态。正常 Binder 发送回执仅代表请求已发送，不代表实体门已打开。研究记录确认过 OEM 原车按钮的实体开启，但普通应用到正式地图 UI 的实际车机写入仍需人工验收。界面显示瞬时按压反馈，不显示选中态。

## 设置入口

精简版仅保留顶栏信息、沉浸状态栏/底栏显示、歌词/平台、背景和一般交互偏好。车型自检/导入、手势映射、红绿灯提醒、Dock 数量/名称和布局编辑入口不展示。

## 当前验证边界

本机定向 runtime/UI 回归、静态自检与正式签名构建结果由本轮验证记录维护；APK 安装/启动只验证应用和分屏链路，不自动点击车控。手套箱实体动作、车窗状态回流、点击手感和完整界面由用户现场验收。
