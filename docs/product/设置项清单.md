# 设置项清单

> **职责：** 用户可保存的呈现偏好、默认值和持久化字段。车辆状态、媒体播放、媒体来源、亮度、音量和车控命令仍由快捷页或媒体卡拥有；设置页不复制这些入口。页面形态、标准控件与主题角色见[设置页UI规则](设置页UI规则.md)。

## 统一规则

1. 设置以稳定ID保存，不用数组下标；未知ID和错误类型单项回退，不使整份设置失效。
2. 显示偏好、歌词排版、氛围、Dock数量、反馈及歌词平台在Activity重建、地图收放和应用重启后保持。
3. 设置只表达偏好；实际读数和命令仍由唯一Store／Port／Adapter链路提供。歌词平台消费既有歌词／封面调度，不改原厂媒体来源仲裁。
4. 滑条显示并预览临时草稿，结束一次保存；取消、退出、禁用或后台打断不保存。按钮统一单次点击声，连续拖动静音。
5. 设置入口在快捷页和Dock保留。每次从普通入口打开回首页；歌词专用入口直达歌词子页。子页返回首页、首页返回关闭，Apple登录层先关闭自身。

设置容器固定在左侧初始1/3区域，不随歌词全屏增宽；普通分屏时左右与Dock对齐，可见表面底部对齐媒体卡底部、外层host裁剪底部对齐Dock可见顶部（640px参考为932／948px，中间16px留给阴影）。阴影由独立mask绘制包络容纳，内容、滚动及输入仍裁剪在原表面边界；阴影不计入Dock可见高度或外边距。返回／收起热区铺满标题行并分别贴两侧，开关标签保持被动，仅右侧完整项目热区切换；96dp标题按钮热区、108dp开关热区及78dp／自然多行项目高度的统一合同见[设置页UI规则](设置页UI规则.md)。首页为外置标题的图标／名称／箭头分组行，子页固定标题、下方独立滚动，歌词页没有预览。Apple登录调起独立03浏览器，不受设置宽度限制；未安装提示安装，用户点击浏览器“完成登录并返回03地图”后直接回到歌词设置，无白色交付页／深色双按钮页；验证进度和重试内联显示，已登录时仅显示“已登录 · 实际中文地区”，同一按钮由登录切换为断开。

Apple Music连接状态仅为真实账号元数据，用户在03浏览器中的Apple官方页面输入账号信息；必需凭据存在才定向返回地图，经官方账号接口验证通过后复用既有加密私有存储。设置暂停不取消外部会话，不要求手填token；取消、旧回执或验证失败不覆盖此前有效账号，也不把尚未验证的连接显示为可用在线来源。真实账号／订阅／地区歌词验收另记，不由本机UI测试代替。

## 持久化字段

呈现偏好仍属于`content_preferences_v1`，schema为10；新增12个`gesture_action_<command.key>`键，稳定ID为`two / three / four`与`up / down / left / right`的组合，值为`none / enter_immersive / exit_immersive`。缺项迁移为二指右进入、二指左退出，其余无；未知值或错误类型仅对应项回退，无其它偏好重置。显式保存的“无”不会恢复成默认动作，State／UI共用不可变完整映射。

版本1..5从原`lyrics_font_scale`迁移为普通40×scale、当前48×scale、全屏120×scale；原三档`lyrics_line_spacing`按28×`0.75 / 1 / 1.35`迁移普通间距，全屏为其三倍；按新滑条网格取整。旧字体／间距API与字段继续保留兼容。已有schema6缺失或损坏的全屏字段分别回退120sp／84dp，不联动普通偏好或重置其它已保存项。版本<=6新增全屏当前字号按已恢复的全屏普通×普通当前／普通字号迁移，并按2sp网格约束；schema7缺失或损坏单项默认144sp且不小于全屏普通。旧充电总开关仅在迁移时复制为四项，旧false仍维持全部隐藏；新版每项独立，重新开启某项不再受遗留总开关压制。新增续航、顶栏保持分屏、翻译和注音均默认true。

歌词平台仍使用既有独立`content.lyrics.providers / preferred_platform`，AUTO保存空ID，其余为对应Provider稳定ID；不复制到呈现偏好Store。Apple连接和加密凭据由既有`AppleMusicConnection`／私有credential store拥有，UI状态、打开页面和登录attempt均不进入普通偏好。

`current_page_id`继续恢复上次页面；旧Renderer所需`current_control_id`、`dock_slot_*`和手动档记忆维持原链。`interaction_gesture_bar_reminder`只保v5历史数据兼容，当前无设置入口或Host提醒调度。schema1..7新增行车自动关闭默认为开启；schema8保留显式false，缺失或错误类型单项回退开启；schema8缺少歌词注音键时默认开启，schema9保存显式值，缺失或错误类型仍单项回退开启。设置打开、收起状态、分组、草稿、反馈与档位转换序号不持久化。

Dock总数默认5，仍恢复有效已保存的3..6；缺失、损坏或未来版本不可解释值单项回退5，不重置schema9其它偏好。原media_show_source_switcher仅保旧数据兼容，不再控制媒体、全屏媒体或歌词错误态来源入口。
