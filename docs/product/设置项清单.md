# 设置项清单

> **职责：** 用户可保存的呈现偏好、默认值和持久化字段。车辆状态、媒体播放、媒体来源、亮度、音量和车控命令仍由快捷页或媒体卡拥有；设置页不复制这些入口。页面形态、标准控件与主题角色见[设置页UI规则](设置页UI规则.md)。

## 统一规则

1. 设置以稳定ID保存，不用数组下标；未知ID和错误类型单项回退，不使整份设置失效。
2. 显示偏好、歌词排版、氛围、Dock数量、反馈及歌词平台倾向在Activity重建、地图收放和应用重启后保持。
3. 设置只表达偏好；实际读数和命令仍由唯一Store／Port／Adapter链路提供。平台倾向消费既有歌词／封面调度，不改原厂媒体来源仲裁。
4. 滑条显示并预览临时草稿，结束一次保存；取消、退出、禁用或后台打断不保存。按钮统一单次点击声，连续拖动静音。
5. 设置入口在快捷页和Dock保留。每次从普通入口打开回首页；歌词专用入口直达歌词子页。子页返回首页、首页返回关闭，Apple登录层先关闭自身。

设置及官方Apple登录页面始终限制在左侧初始1/3小屏区域，宽度固定读取地图展开分屏端点，不随歌词全屏增宽。普通分屏时设置左右与Dock、底边与媒体卡底边对齐。首页为图标／名称／箭头分组行；歌词页固定标题和三句示例预览，从歌曲平台倾向开始的设置列表独立滚动。

Apple Music连接状态仅为真实账号元数据，用户从“登录 Apple Music”在官方WebView中输入；登录成功复用既有加密私有凭据存储。关闭页面、返回或后台停止Cookie检查并销毁WebView，不要求手填token，也不把尚未登录的状态显示为可用在线来源。真实账号／订阅／地区歌词验收另记，不由本机UI测试代替。

## 持久化字段

呈现偏好仍属于`content_preferences_v1`，schema为6：

```text
preferences_version = 6
top_bar_show_weekday
top_bar_show_seconds
top_bar_show_indoor_temperature
top_bar_show_battery
top_bar_show_charging_status
lyrics_font_size_sp
lyrics_current_font_size_sp
lyrics_line_gap_dp
lyrics_alignment
lyrics_color_mode
lyrics_custom_color
lyrics_current_color_mode
lyrics_current_custom_color
lyrics_immersive_font_size_sp
lyrics_immersive_line_gap_dp
lyrics_speaker_layout
lyrics_highlight
lyrics_immersive_show_top_bar
lyrics_immersive_show_dock
ambient_show_artwork
media_show_source_switcher
dock_button_count
interaction_show_action_feedback
ui_opacity
```

版本1..5从原`lyrics_font_scale`迁移为普通40×scale、当前48×scale、全屏120×scale；原三档`lyrics_line_spacing`按28×`0.75 / 1 / 1.35`迁移普通间距，全屏为其三倍；按新滑条网格取整。旧字体／间距API与字段继续保留兼容。已有schema6缺失或损坏的全屏字段分别回退120sp／84dp，不联动普通偏好或重置其它已保存项。

歌词平台仍使用既有独立`content.lyrics.providers / preferred_platform`，AUTO保存空ID，其余为对应Provider稳定ID；不复制到呈现偏好Store。Apple连接和加密凭据由既有`AppleMusicConnection`／私有credential store拥有，UI状态、打开页面和登录attempt均不进入普通偏好。

`current_page_id`继续恢复上次页面；旧Renderer所需`current_control_id`、`dock_slot_*`和手动档记忆维持原链。`interaction_gesture_bar_reminder`只保v5历史数据兼容，当前无设置入口或Host提醒调度。设置打开状态、分组、草稿与反馈不持久化。
