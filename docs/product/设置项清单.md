# 设置项清单

> **职责：** 用户可保存的偏好、默认值和持久化字段。用户可见功能定义见 [产品需求基线](产品需求基线.md)，运行时状态和数据源见 [内容区主链](../architecture/内容区主链.md)。

## 统一规则

1. 设置以稳定 ID 保存，不用数组下标；未知 ID 过滤，新项目补默认值。
2. 页面、主页、控制区、Dock 排序和显示状态在 Activity 重建、地图收放及应用重启后保持。
3. 设置只表达偏好，不直接读取车机字段或执行车控命令；车控由快捷入口经统一命令端口执行，设置只保存显示、排序和反馈偏好，不创建第二套动画或几何主链。
4. 存储带版本号和迁移；单项失效不能使整份设置失效。

## 用户偏好

| 项目 | 默认值 | 规则 |
|---|---|---|
| 页面顺序 / 主页 | `shortcuts → lyrics` / `lyrics` | 以稳定 `pageId` 保存 |
| 星期 / 秒数 | 开启 / 关闭 | 默认顶栏示例 `HH:mm·星期日`；非默认充电状态为紧凑 `HH:mm`，秒数开启时各自加 `:ss`；不显示日期 |
| 车内温度 / 电量 / 充电状态 | 显示 | 单行顶栏按真实充电状态切换温度／状态；电量数字保留在无障碍说明，不因为偏好伪造读取值 |
| Dock 顺序 / 显示 | 车锁固定；`shortcuts → seat_ventilation → seat_heating → seat_massage → settings` / 全显示 | 右侧五项可替换和排序；设置入口必须可恢复 |
| 控制区顺序 | `media → climate` | 只调整媒体 / 空调卡片 |
| 歌词字号 / 行距 | 标准 / 标准 | 通过统一呈现规格派生 |
| 当前行高亮 / 专辑封面 | 开启 / 开启 | 控制歌词视觉 |
| 歌词滚动策略 | 当前行居中 | 仅选择已实现策略 |
| 全屏媒体栏 / 来源切换入口 | 开启 / 开启 | 媒体栏仅在沉浸式状态显示 |
| 顶部浮层自动隐藏 / 时长 | 开启 / `3s` | 可选 `2s`、`3s`、`5s` |
| 车控结果提示 / 执行中状态 | 开启 / 开启 | 成功必须等待状态回流 |
| 不可用能力入口 | 保留并置灰 | 不可用不等于删除能力 |

普通分屏不显示媒体进度拖动；沉浸式全屏只在底层能力支持时显示。当前歌词页控制范围为播放 / 暂停、下一首和媒体来源切换，不含上一首。
