# 设置项清单

> **职责：** 用户可保存的呈现偏好、默认值和持久化字段。车辆状态、媒体播放、媒体来源、亮度、音量和车控命令仍由快捷页或媒体卡拥有；设置页不复制这些入口。

## 统一规则

1. 设置以稳定 ID 保存，不用数组下标；未知 ID 过滤，新项目补默认值。
2. 页面、显示偏好、歌词排版、氛围、Dock 数量和反馈偏好在 Activity 重建、地图收放及应用重启后保持。
3. 设置只表达偏好，不直接读取车机字段或执行车控命令；实际读数和命令仍由原有 Store / Port / Adapter 链路提供。
4. 存储带版本号和迁移；单项失效回退该项默认值，不能使整份设置失效。
5. 设置入口在快捷页和 Dock 中保留；Dock 的设置入口始终存在，避免用户把设置隐藏后无法恢复。

## 当前可用偏好

| 分组 | 项目 | 默认值 | 规则 |
|---|---|---:|---|
| 顶栏 | 星期 | 开启 | 时间旁显示星期名称 |
| 顶栏 | 秒数 | 关闭 | 时间由 `HH:mm` 切换为 `HH:mm:ss` |
| 顶栏 | 车内温度 | 显示 | 有空间时显示真实车内温度，数据无效时不伪造读数 |
| 顶栏 | 电量图标 | 显示 | 控制顶栏电池图标及其充电符号的显示 |
| 顶栏 | 充电信息 | 显示 | 控制插枪、预约、充电完成和充电功率文字 |
| 歌词 | 歌词字号 | 标准 | `0.85× / 1.00× / 1.15×`，当前行和普通行一起调整 |
| 歌词 | 行间距 | 标准 | 紧凑、标准、宽松三档调整句间留白；段内换行沿用自然行高 |
| 歌词 | 按声部布局 | 开启 | 仅影响已有声部信息的左右呈现，不生成新的声部身份 |
| 歌词 | 强调当前行 | 开启 | 关闭后仍跟随真实播放位置，只取消当前行视觉强调 |
| 封面氛围 | 模糊封面背景 | 显示 | 控制内容区下层动态柔光；关闭时停止氛围烘焙任务 |
| 媒体 | 来源切换入口 | 开启 | 同时控制媒体卡和歌词空态的来源入口，不提供来源选择本身 |
| Dock | Dock 显示按钮 | `6` | 可选 `3 / 4 / 5 / 6`；车锁在左，设置在右，隐藏项只改变 Dock 呈现 |
| 交互 | 界面透明度 | `100%` | 可选 `20% / 40% / 60% / 80% / 100%`；作用于完整内容区，包括设置浮层，低于20%或无效值恢复默认 |
| 交互 | 操作结果提示 | 开启 | 控制失败或状态未确认时的反馈浮层；关闭清理当前提示，隐藏期间的新提示不回放 |

设置页是与 Dock 左右边界对齐、底边与媒体卡底边对齐的大型浮动面板；顶部整段手势区域覆盖完整上缘热区，下面的详情区域独立承担纵向滚动；点击 Dock 或快捷页的设置按钮会在打开与关闭之间切换。

## 持久化字段

```text
preferences_version = 3
top_bar_show_weekday
top_bar_show_seconds
top_bar_show_indoor_temperature
top_bar_show_battery
top_bar_show_charging_status
lyrics_font_scale
lyrics_line_spacing
lyrics_speaker_layout
lyrics_highlight
ambient_show_artwork
media_show_source_switcher
dock_button_count
interaction_show_action_feedback
ui_opacity
```

`current_page_id`继续恢复上次当前页面，不伪装成独立的启动页面偏好。旧 Renderer 兼容所需的 `current_control_id`、`dock_slot_*` 和车控手动档记忆继续由既有兼容链维护；它们不构成当前 Compose 设置页的菜单项。
