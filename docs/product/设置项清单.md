# 内容区设置项清单

> 状态：`v0.1`，依据 2026-09-25 已确认的内容区结构整理。本文只定义用户能理解和操作的设置项；具体控件是否可用仍以车机能力验证结果为准。所有设置必须由统一的 `ContentPreferenceStore` 持久化，不能由页面或 Renderer 各自写入偏好。

## 1. 设置原则

1. 设置项按用户任务分类，不按内部类名或底层车机属性分类。
2. 每个设置项使用稳定 `preferenceKey`，默认值集中定义，页面只读取和提交变更意图。
3. 页面排序、主页、控制区排序、Dock 排序和显示状态属于应用级偏好；Activity 重建、地图收放和应用重新启动后仍然保持。
4. 设备能力未验证或暂时不可用时，设置项不得伪造可用；应显示“暂不可用”或隐藏尚未发布的选项，并保留诊断依据。
5. 恢复默认只恢复对应分类，不清除媒体、车辆运行状态或地图导航状态。

## 2. 页面与主页

| 设置项 | 默认值 | 用户作用 |
|---|---|---|
| 主页 | `lyrics`（歌词页） | 进入内容区时首先展示的页面 |
| 页面排序 | 快捷功能 → 车辆信息 → 歌词 → 投屏 | 调整单页横向切换顺序 |
| 恢复默认页面顺序 | 不适用 | 将页面顺序和主页恢复为默认值 |

页面使用稳定 ID 保存，不使用当前数组下标保存。页面排序改变后，主页仍通过 `pageId` 指向原页面；如果用户隐藏了某个页面，主页不能指向已隐藏页面。

## 3. 顶栏与时间

### 3.1 已确定的时间设置

| 设置项 | 默认值 | 规则 |
|---|---|---|
| 显示日期 | 关闭 | 开启后在时间旁显示当前日期 |
| 显示星期 | 关闭 | 开启后显示当前星期 |
| 显示秒数 | 关闭 | 关闭时使用 `HH:mm`，开启后固定使用 `HH:mm:ss` |

时间格式不开放自由输入。日期、星期和秒数是独立开关；时间显示仍由单一系统时钟适配器驱动，不能为每个控件单独创建定时器。

### 3.2 车况状态显示设置

以下是明确可设置、但需要结合车机能力和首版视觉验证收敛的显示项：

1. 显示车内温度。
2. 显示动力电池电量。
3. 显示充电连接 / 充电状态。

默认由产品基线决定为顶栏可见信息；若对应字段未验证或不可用，不能以车外温度或猜测值替代。设置层只控制显示，不改变车辆状态订阅和数据读取。

## 4. Dock

### 4.1 已确定的设置

| 设置项 | 默认值 | 用户作用 |
|---|---|---|
| Dock 项目排序 | 车锁 → 座椅通风 → 座椅加热 → 方向盘加热 → 设置 | 调整高频入口顺序 |
| Dock 项目显示 / 隐藏 | 默认全部显示 | 隐藏不常用入口；设置入口必须始终可恢复 |
| 恢复默认 Dock | 不适用 | 恢复默认顺序并显示默认项目 |

Dock 项目和快捷功能页共享同一 `ShortcutCatalog`。隐藏 Dock 项目不等于删除快捷功能能力；用户仍可从快捷功能页管理它。核心“设置”入口不得被隐藏到不可恢复的状态。

## 5. 控制区

### 5.1 已确定的设置

| 设置项 | 默认值 | 用户作用 |
|---|---|---|
| 控制模块排序 | 媒体 → 空调 | 调整控制区横向切换顺序 |
| 恢复默认控制区 | 不适用 | 恢复媒体、空调的默认顺序 |

座椅不作为控制区模块；座椅通风和座椅加热通过 Dock 与快捷功能页进入。

### 5.2 可选增强设置

控制模块显示 / 隐藏可以作为后续设置项，但必须满足：

1. 至少保留一个可用控制模块。
2. 隐藏模块不会删除其业务能力，只改变控制区入口。
3. 控制区设置不能改变地图面板几何，也不能绕过 `ContentPresentationCoordinator`。

## 6. 歌词与媒体

| 设置项 | 默认值 | 用户作用 |
|---|---|---|
| 歌词字号 | 标准字号 | 调整歌词阅读大小 |
| 歌词行距 / 段间距 | 标准间距 | 调整阅读密度 |
| 当前行高亮 | 开启 | 设置当前行的高亮样式和颜色 |
| 歌词滚动策略 | 当前行居中 | 在可用策略中选择滚动方式 |
| 专辑封面 | 开启 | 控制普通分屏和沉浸式页面的封面显示 |
| 全屏媒体控制栏 | 开启 | 控制沉浸式全屏时的大专辑封面和媒体控制栏显示 |
| 媒体来源切换入口 | 开启 | 控制歌词页是否显示媒体来源切换入口 |

媒体控制范围固定为：播放 / 暂停、下一首、媒体来源切换。普通分屏不显示进度拖动；进入沉浸式全屏后，仅在底层媒体能力支持时显示进度拖动。上一首不进入本项目的歌词页控制栏。

歌词字号、行距、封面和全屏媒体栏的实际视觉值必须通过统一 `ImmersiveTransitionSpec` 派生；设置项不能创建第二套动画主链。

## 7. 交互与反馈

| 设置项 | 默认值 | 用户作用 |
|---|---|---|
| 顶部控件浮层自动隐藏 | 开启 | 歌词 / 投屏页顶部交互后自动隐藏入口 |
| 浮层自动隐藏时长 | `3s` | 可选 `2s`、`3s`、`5s`；不提供永久常驻，避免遮挡内容 |
| 车控结果提示 | 开启 | 显示成功、失败、不可用结果 |
| 车控执行中状态 | 开启 | 显示忙碌状态并防止重复提交 |
| 不可用能力入口 | 保留并置灰 | 让用户知道能力存在但当前不可用；后续可作为高级设置调整 |

所有提示都由统一交互状态驱动。点击完成不等于车控成功，按钮必须等待状态回流后再显示成功结果。

## 8. 统一持久化边界

`ContentPreferenceStore` 至少保存以下字段：

```text
pageOrder
homePageId
controlOrder
dockOrder
dockVisibility
topBar.showDate
topBar.showWeekday
topBar.showSeconds
topBar.showIndoorTemperature
topBar.showBattery
topBar.showChargingStatus
lyrics.fontScale
lyrics.lineSpacing
lyrics.highlightStyle
lyrics.scrollStrategy
lyrics.showArtwork
lyrics.showFullscreenControls
lyrics.showMediaSourceSwitcher
interaction.overlayAutoHide
interaction.overlayTimeout
vehicle.showUnavailableActions
vehicle.showActionFeedback
```

存储升级必须有版本号和默认值迁移。未知 `pageId`、`controlId` 或 `dockItemId` 在读取时过滤，缺失的新项目按注册表默认值补齐；不能因为单个项目被移除而让整个设置文件失效。
