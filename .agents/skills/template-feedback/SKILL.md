# 模板能力回流

## 判断

1. 仅地图包名、版本、Smali 路径、车机坐标、设备 serial、地图协议和历史实验留在 03地图。
2. 可回流候选只包括通用的 Skill 结构、证据等级、文档路由、验证分层和具体个人风险判断，不迁入其它项目的禁令。
3. 不能证明跨项目复用时，只记录“候选通用能力”，不修改 NewProject 或其它仓库。

## 步骤

1. 读取当前项目相关规则、Skill、docs/README.md 和进度。
2. 读取模板源 AGENTS.md 及目标文件，先检查其 Git 状态，不覆盖用户改动。
3. 去掉产品、路径、业务和历史兼容后，再以最小 diff 回流；未经用户明确要求不提交或推送模板源。
4. 在当前项目记录候选内容、回流结果和验证；两边分别执行各自检查。
